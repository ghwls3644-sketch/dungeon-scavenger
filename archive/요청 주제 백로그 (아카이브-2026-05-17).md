# 요청 주제 백로그 (운영본 v2)

하네스 실행 시 `이번 요청 주제`는 아래 목록에서 선택한다.
결과물은 `GDD 반영 판정` 기준으로 이력을 기록한다.

## 1) 운영 규칙
- 주제는 1줄로 입력한다.
- 동일 주제 재실행은 `v2`, `v3`로 버전 태그를 붙인다.
- `AUTO_MERGE`만 GDD 반영 대상으로 처리한다.

## 2) 빠른 입력 형식
```text
이번 요청 주제: [주제 ID] [주제명]
```

예시:
```text
이번 요청 주제: T-03 탈출 경로 사전 개척(지름길) 시스템 설계
```
