# 던전 정설

## 목적

던전, 코어, 폐던전, 잔여 구역, 잔존 에너지가 세계관상 가능한지를 판단하는 상세 정설을 관리한다.

## 포함 범위

- 던전과 코어의 성격 및 코어 방
- 범람, 코어 파괴, 자가 복구 상실
- 폐던전과 잔여 구역의 범위
- 잔존 에너지의 작용과 한계
- 반복 탐험의 세계관상 이유와 최종 소멸

## 제외 범위

- 방문 간 실제 상태 전환과 랜덤 규칙
- 공식 용어의 짧은 정의
- 개별 던전의 구현 데이터
