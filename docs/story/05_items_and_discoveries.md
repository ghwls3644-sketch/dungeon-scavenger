# 아이템과 발견물

## 목적

아이템 분류의 세계관 의미와 발견물이 담당하는 서사적 역할을 관리한다.

## 포함 범위

- 폐품, 잔재, 고유 유물, 핵심 기록물, 미확인 물품의 의미
- 분류별 원본성과 반복 등장 개연성
- 감정과 연구자 보관의 세계관상 의미
- 실패한 수색꾼의 흔적과 잔여 구역 단서

## 제외 범위

- 스폰, 판매 차단, 저장 플래그, UI 표현 규칙
- 아이템 설명의 문장 길이와 어조
- 공식 표기와 짧은 정의

## 책임 경계

- 이 문서는 아이템과 발견물이 세계 안에서 무엇이며 왜 중요한지, 원본인지 반복 가능한 흔적인지, 어떤 서사 단서를 전달하는지를 소유한다.
- 공식 표기와 짧은 정의는 [`../reference/glossary.md`](../reference/glossary.md)가 소유한다.
- 스폰, 감정 상태, 판매·폐기 보호, 저장 플래그와 UI 구분은 [`../design/item_rules.md`](../design/item_rules.md)가 소유한다.
- 발견·등록·재열람 흐름과 NPC 반응 조건은 [`../design/narrative_delivery.md`](../design/narrative_delivery.md), 정보가 열리는 진행 순서는 [`06_narrative_progression.md`](06_narrative_progression.md)가 소유한다.
- 반복 방문별 배치와 지도·구역 상태 변화는 [`../design/repeat_exploration.md`](../design/repeat_exploration.md)가 소유한다.
- 아이템 설명의 길이와 문체는 [`07_tone_and_writing_guide.md`](07_tone_and_writing_guide.md), NPC가 아는 내용과 태도는 [`04_characters_and_factions.md`](04_characters_and_factions.md)가 소유한다.

## 아이템 분류의 서사 의미

아이템 분류는 게임 보상 구조와 스토리 전달 방식을 동시에 담당한다. 현재 [`../GDD.md`](../GDD.md)는 `잔류물`을 길드·행정이 회수 가능한 물품 전체의 상위 표현으로 사용한다. 이 문서는 그 아래 실제 분류의 서로 다른 원본성과 서사 기능만 상세화한다.

| 분류 | 세계관상 의미 | 서사 기능 | 원본성과 재등장 개연성 |
|---|---|---|---|
| 미확인 물품 | 아직 감정되지 않아 정체를 모르는 임시 상태 | 가치와 위험을 판단하기 전의 불확실성을 만듦 | 감정 후 폐품·잔재·고유 유물 등 실제 분류가 드러남 |
| [`폐품`](../reference/glossary.md#폐품) | 물리적으로 남은 잡동사니와 부품 | 생존 경제와 수색꾼의 노동을 보여줌 | 단일 원본이 아니며 축적된 잔량, 새로 드러난 물건, 다른 탐험자가 남긴 물건으로 반복 발견 가능 |
| [`잔재`](../reference/glossary.md#잔재) | 마력과 기억의 흔적이 엉긴 물질 또는 현상 | 감정과 수집을 통해 과거의 단서와 불길한 흔적을 전달함 | 잔존 에너지가 비슷한 흔적을 다시 응축할 수 있지만 특정 원본을 재생성하는 것은 아님 |
| [`고유 유물`](../reference/glossary.md#고유-유물) | 특정 사건이나 인물과 연결된 단 하나의 원본 물품 | 수집, 정보 해금, 관련 NPC 보상으로 사건의 흔적을 남김 | 원본이 하나뿐이므로 한 번 회수한 뒤 다시 등장하지 않음 |
| [`핵심 기록물`](../reference/glossary.md#핵심-기록물) | 던전·코어·인물·사건의 진실을 여는 원본 기록 | 연구자 보관과 목록을 통해 세계관 해석을 확장함 | 원본 기록물이므로 한 번 회수한 뒤 다시 등장하지 않음 |

재등장 여부의 실제 데이터와 확률은 [`../design/item_rules.md`](../design/item_rules.md)가 담당한다. 반복 발견의 세계관상 한계는 [`02_dungeon_canon.md#반복-탐험이-가능한-세계관상-이유`](02_dungeon_canon.md#반복-탐험이-가능한-세계관상-이유)를 따른다.

### 분류별 처리의 의미

- 폐품은 싸구려일 수 있지만 생존 경제의 기반이며, 판매·제작·수리에 쓰이는 일반 회수품이다.
- 잔재는 돈이 될 수도 있고 불길한 단서가 될 수도 있으며, 감정을 통해 실제 흔적과 가치가 드러난 뒤 판매·수집·연구 의뢰로 이어질 수 있다.
- 고유 유물과 핵심 기록물은 일반 상품보다 수집과 정보 해금에 가까운 원본이다.
- 미확인 물품은 독립된 최종 종류가 아니라 감정 전 지식 상태다.

판매 가능 여부, 제작·수리 재료 처리와 감정 전후 상태 전환은 Story 설정이 아니라 [`../design/item_rules.md`](../design/item_rules.md)의 구현 책임이다.

## 감정과 연구자 보관의 의미

감정은 미확인 물품의 실제 분류와 가치를 알아내는 과정이다. 잔재의 경우 단순히 가격을 확인하는 데 그치지 않고, 마력과 기억의 흔적을 읽어 과거 사건이나 장소의 단서를 드러내는 서사적 입구가 된다. 감정사 역할과 태도는 [`04_characters_and_factions.md#감정사와-감정-방식`](04_characters_and_factions.md#감정사와-감정-방식)가 담당한다.

핵심 기록물은 연구자 [`NPC-005`](../reference/entity_index.md)에게 가져가 보관하고, 이후 기록 목록이나 도감처럼 다시 확인할 수 있게 하는 방향이 어울린다. 이 구조는 박물관에 자료를 기부해 목록을 채우는 방식과 비슷한 의미를 가진다.

- 원본 기록물을 일반 상품처럼 소모하지 않고 보존한다.
- 수집이 쌓이며 세계를 얼마나 이해했는지 보여준다.
- 연구자가 필요할 때 짧은 해설을 덧붙일 근거가 된다.
- 세계관 설명을 강제로 밀어 넣지 않고 플레이어가 원할 때 확인하게 한다.

실제 등록·저장·재열람 절차는 [`../design/narrative_delivery.md`](../design/narrative_delivery.md)와 [`../design/item_rules.md`](../design/item_rules.md)가 담당한다.

## 잔재의 기억 흔적

잔재는 일반 폐품이나 확인되지 않은 저주 물품과 같은 말이 아니다. 마력과 기억의 흔적이 엉긴 대상이며, 감정을 통해 원래 사건이나 마력 반응의 일부를 추론할 수 있다. 다만 하나의 잔재가 세계관 전체를 직접 설명하거나 객관적 진실을 완전하게 재생하지는 않는다.

현재 표현은 열기, 진동, 문양과 마력 같은 관찰 가능한 흔적을 짧은 텍스트로 전달하는 방향이다. 실제 문장 구조와 예시는 [`07_tone_and_writing_guide.md#잔재-설명-문체`](07_tone_and_writing_guide.md#잔재-설명-문체)가 소유하며, 환청·환시·대규모 환경 변화는 현재 범위에서 보류한다.

## 반복 발견의 개연성

폐품이 반복 등장하는 이유를 매번 자세히 설명할 필요는 없다. 다만 다음과 같은 흔적을 가끔 보여 주면, 던전이 새 물건을 만들어 낸 것이 아니라 남아 있던 물건이 뒤늦게 드러났다는 느낌을 줄 수 있다.

- 새로 무너진 잔해 사이에서 물건이 드러남
- 다른 수색꾼이 두고 간 낡은 장비가 발견됨
- 이전에는 막혀 있던 틈에서 작은 부품이 굴러나옴
- 소멸 중인 방의 구조가 바뀌며 숨은 물건이 노출됨

잔재는 잔존 에너지가 비슷한 흔적을 다시 응축하면서 낮은 빈도로 발견될 수 있다. 반대로 고유 유물과 핵심 기록물은 원본이므로 이 설명으로 재등장시킬 수 없다. 폐던전의 물품 노출 원리는 [`02_dungeon_canon.md#잔존-에너지-유실과-물품-노출`](02_dungeon_canon.md#잔존-에너지-유실과-물품-노출), 실제 스폰 처리는 관련 Design 문서가 담당한다.

## 발견물과 서브 스토리

스토리는 긴 설명보다 발견물, 짧은 기록, 아이템 설명, 필요한 NPC 반응과 구역 변화로 전달하는 방식이 어울린다. 발견물은 다음과 같은 서브 스토리 유형을 담당한다.

| 유형 | 예시 발견물 | 보상 / 기능 |
|---|---|---|
| 유명 모험가의 흔적 | 버려진 표식, 찢긴 공략 지도, 파손된 장비 | 화려한 모험가 시대의 이면을 보여줌 |
| 실패한 수색꾼 | 낡은 배낭, 피 묻은 밧줄, 개인 표식, 지워진 공략도 가장자리 | 위험 경고, 잔여 구역 힌트, 직업군의 현실감 제공 |
| 던전 발생 기록 | 지맥 조사서, 마나 이상 관측 기록 | 자연 발생 던전의 단서 제공 |
| 코어 연구 기록 | 감정 보고서, 마력 회로 도면, 파편 분석표 | 코어 원리와 잔재 규칙 해금 |
| 회수 시장의 기록 | 거래 장부, 감정 수수료 명세, 허가증 | 폐던전 경제와 착취 구조 전달 |
| 봉인과 소문 | 성직자의 경고문, 오래된 부적, 민간 전승 | 마왕과 던전을 혼동하는 사회적 불안 전달 |
| 봉쇄된 하층 단서 | 녹슨 열쇠, 봉인문 사본, 지워진 층수 표기 | 장기 목표와 핵심 미스터리 암시 |

### 맥락 있는 발견

발견물은 아무 곳에서나 완전히 무작위로 나타나기보다 장소와 내용의 맥락이 맞아야 한다. 기록실에서는 기록물, 폐숙소에서는 생활 흔적, 경비실에서는 장치 부품처럼 구역이 발견물의 후보 범위를 설명한다. 그 안에서 무엇을 어떤 방식으로 배치할지는 [`../design/narrative_delivery.md`](../design/narrative_delivery.md)와 [`../design/repeat_exploration.md`](../design/repeat_exploration.md)가 담당한다.

### 짧은 단서와 깊은 해설

발견물 자체는 현장에서 이해할 수 있는 첫 단서를 제공하고, 기록물이나 특이한 잔재를 연구자에게 가져가면 더 깊은 설명을 얻을 수 있다. 이 관계는 플레이어가 세계관 설명을 즉시 읽도록 강제하지 않으면서, 관심 있는 발견을 나중에 다시 해석할 수 있게 한다.

아이템 설명의 실제 길이와 어조는 [`07_tone_and_writing_guide.md`](07_tone_and_writing_guide.md), 획득·등록·해설·재열람 순서는 [`../design/narrative_delivery.md`](../design/narrative_delivery.md), 진행 단계별 정보 깊이는 [`06_narrative_progression.md`](06_narrative_progression.md)가 담당한다.

### 필요한 담당자만 반응

같은 발견물을 모든 NPC에게 보여 주는 복잡한 반응 구조는 사용하지 않는다. 아이템의 의미에 맞는 담당자만 반응한다.

| 발견물 | 필요한 반응 역할 |
|---|---|
| 폐품 | 상인 또는 길드 |
| 미확인 잔재 | 감정사 |
| 기록물 | 연구자 |
| 마왕·봉인 관련 물건 | 성직자의 짧은 반응 가능 |
| 일반 수집품 | 특별한 NPC 반응 없이 목록 등록 가능 |

각 NPC가 무엇을 알고 어떻게 받아들이는지는 [`04_characters_and_factions.md`](04_characters_and_factions.md), 실제 반응 조건은 [`../design/narrative_delivery.md`](../design/narrative_delivery.md)가 담당한다.

## 지도 발견물과 잔여 구역

지도 발견물은 아직 완성되지 않은 새 지도가 아니라, 이미 존재하는 공략도와 실제 폐던전 상태 사이의 어긋남을 보여 주는 단서다. 수색꾼이 들어가는 폐던전은 기본적으로 한 번 이상 공략되었고, 주요 공략 루트는 길드나 과거 공략대의 지도에 남아 있을 가능성이 높다.

| 표현 | 의미 | 사용 방식 |
|---|---|---|
| 손상된 공략도 | 과거 공략대가 사용하던 지도 일부 | 기본 루트와 현재 상태의 차이를 보여줌 |
| 지워진 층수 표기 | 지도에는 있었지만 현재는 무너졌거나 막힌 구역 | 소멸 중인 폐던전의 불안정성 표현 |
| 개인 표식 | 실패한 수색꾼이 남긴 비공식 표시 | 잔여 구역 후보를 암시함 |
| 지도 가장자리의 덧그림 | 공식 지도 바깥에 누군가가 적어둔 흔적 | 지도에 없는 틈새 공간을 찾는 힌트 |
| 좌표 조각 / 방향 메모 | 완전한 지도가 아니라 부분 단서 | 플레이어가 직접 잔여 구역을 추정하게 만듦 |

핵심은 **공식 지도는 주요 공략 루트 기준으로 완성되어 있지만 잔여 구역은 지도에 빠져 있다**는 구조다. 던전이 코어 파괴 후 불안정해졌기 때문에 지도와 실제 구조가 조금씩 어긋날 수 있다. 지도 발견물은 정확한 정답지가 아니라 잔여 구역을 찾게 하는 부분 단서로 사용한다. 실제 지도 갱신과 구역 개방 처리는 관련 Design 문서가 담당한다.

## 실패한 수색꾼의 흔적

실패하거나 실종된 수색꾼의 흔적은 적나라하게 보여 주기보다 은근하게 반복 등장시키는 편이 어울린다. 같은 이름, 같은 표식, 비슷한 필체와 남겨진 장비가 여러 번 이어지면 플레이어는 자연스럽게 누군가의 흔적을 추적하는 느낌을 받을 수 있다.

- 같은 이름이 적힌 낡은 표식
- 공식 지도 바깥에 남겨진 개인 표식
- 지도 가장자리에 적힌 짧은 방향 메모
- 이전 발견물의 문장과 이어지는 짧은 메모
- 수색꾼들 사이에서만 통하는 은어가 적힌 경고문
- 마지막까지 직접 등장하지 않는 실종자

이 흔적은 잔여 구역을 여는 단서가 되거나, 안쪽으로 들어갔다가 돌아오지 못한 누군가가 있다는 긴장을 남긴다. 해당 역할은 [`NPC-011`](../reference/entity_index.md)로 추적하지만, 한 사람의 연속된 흔적인지 여러 실패 사례인지는 아직 확정하지 않는다. 등장 순서와 실제 구역 개방 조건은 관련 Narrative와 Design 문서가 담당한다.

## 보호 대상의 서사 의미

고유 유물과 핵심 기록물은 일반 상품이 아니라 수집과 세계관 해석을 이어 주는 원본이다. 이를 일반 회수품처럼 처분하면 사건의 흔적과 수집 진행이 끊기므로, 판매보다 등록·정보·보상에 연결하는 방향이 어울린다. 특정 의뢰품 역시 진행 중 필요한 동안에는 같은 보호가 필요할 수 있다.

판매·폐기 차단과 보호 UI는 [`../design/item_rules.md`](../design/item_rules.md)가 소유한다. 이 문서는 왜 해당 물품을 일반 상품으로 취급하지 않는지만 설명한다.
