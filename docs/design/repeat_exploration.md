# 반복 탐험 규칙

## 목적

같은 폐던전을 반복 방문할 때 유지되는 상태와 변하는 요소의 실제 게임 규칙을 관리한다.

## 포함 범위

- 고정 지도와 문·통로 상태 변화
- 위험, 아이템, 적 배치의 랜덤 범위
- 반복 요소와 1회성 요소
- 잔여 구역 및 고유 유물 회수 후 상태 저장
- 잔존 에너지 노출량과 방문 간 상태 전환

## 제외 범위

- 반복 탐험이 가능한 세계관상 원인
- 개별 아이템의 판매·감정·저장 필드
- 실제 맵 콘텐츠와 밸런스 수치 확정
- 발견물 등록·해설·재열람 조건
- 하네스 동작과 위험 대응 수치

## 반복 탐험의 기본 원칙

- 큰 지도, 방의 용도와 입구 위치는 고정한다.
- 방 전체를 방문마다 다시 만드는 완전 절차 생성은 사용하지 않는다.
- 이전 방문에서 익힌 공간 지식이 다음 방문에도 도움이 되어야 한다.
- 변화는 일부 문·통로, 붕괴 지점, 상호작용 오브젝트, 위험과 배치 후보에 제한한다.
- 방문 간 변화는 복구나 재생이 아니라 붕괴, 봉쇄, 오작동과 숨은 대상의 노출로 표현한다.
- 한 방문의 가변 결과는 탐험 시드로 재현할 수 있어야 한다.

## 반복 요소와 1회성 요소

| 구분 | 해당 요소 |
|---|---|
| 반복 | 폐품, 일부 잔재, 함정 오작동, 문과 통로의 상태 변화, 적 또는 골렘의 배치 변화, 붕괴·침수·마력 이상 같은 환경 이벤트, 다른 수색꾼이 남긴 흔적 |
| 1회성 | 고유 유물 원본, 핵심 기록물 원본, 주요 스토리 해금 이벤트, 특정 NPC 반응의 최초 발생, 봉쇄 구역의 첫 개방 이벤트 |

반복 요소도 무제한 복제하지 않고 구역별 후보와 현재 방문 상태 안에서 노출한다. 1회성 요소의 완료 여부는 영구 진행 상태로 저장해 다음 방문 후보에서 제외한다. 특정 NPC 반응의 실제 발생 조건과 재열람은 [`narrative_delivery.md`](narrative_delivery.md), 개별 아이템의 반복 가능 여부는 [`item_rules.md`](item_rules.md)가 소유한다.

## 상태 계층

반복 탐험 상태는 다음 세 계층으로 나눈다.

| 계층 | 유지 기간 | 포함 내용 |
|---|---|---|
| 고정 정의 | 모든 방문 | 큰 지도, 방 연결과 용도, 입구 위치, 구역별 아이템·위험 후보 |
| 영구 진행 상태 | 저장 이후의 모든 방문 | 획득 완료한 고유 유물·기록물, 주요 스토리 해금과 최초 NPC 반응, 첫 구역 개방, 방의 소실·봉쇄·상호작용 감소 |
| 현재 방문 상태 | 한 번의 탐험 | 탐험 시드, 이번에 열린 문·통로, 활성 위험, 아이템·골렘·장치 위치, 임시 획득과 현재 위험 |

고정 정의를 방문마다 덮어쓰지 않는다. 현재 방문 상태는 영구 진행 상태를 바탕으로 생성하며, 이미 소실된 방이나 획득 완료한 원본을 다시 활성 후보로 넣지 않는다.

## 고정 요소와 가변 요소

원본 `TBL-020`의 랜덤성 적용 범위와 추천도는 다음과 같다.

| 범위 | 방식 | 추천도 |
|---|---|---|
| 방 전체 구조 | 매번 크게 바뀌는 절차 생성 | 낮음. 구현과 밸런스 부담이 큼 |
| 방의 출입 상태 | 일부 방이 막히거나 열림 | 높음. 폐던전의 소멸감과 잘 맞음 |
| 아이템 배치 | 구역별 후보 중 랜덤 등장 | 높음. 반복 탐험의 기대감을 만듦 |
| 위험 이벤트 | 붕괴, 소음, 함정 오작동 등이 확률 발생 | 높음. 긴장감 유지에 좋음 |
| 적 배치 | 고장 난 골렘이나 잔존 몬스터 위치 변화 | 중간. 전투 비중에 따라 조절 |
| 다른 수색꾼 흔적 | 내부 직접 만남보다 랜덤 흔적 발견 | 높음. 홀로 탐험하는 감각 유지 |

현재 적용 방향은 **고정된 큰 지도 + 구역별 랜덤 아이템·위험 이벤트 + 일부 방의 출입 변화**다. 이를 방문 간 상태로 나누면 다음과 같다.

| 범위 | 적용 규칙 | 상태 |
|---|---|---|
| 방 전체 구조 | 큰 지도와 방의 정체성을 고정함 | 방문 간 고정 |
| 입구 | 진입과 유일한 기본 탈출 지점으로 유지함 | 방문 간 고정 |
| 문·통로 | 일부 후보만 잠김·막힘·개방됨 | 방문별 가변 또는 영구 봉쇄 |
| 아이템 | 방별 후보 풀 안에서 위치와 종류가 달라짐 | 방문별 가변 |
| 위험 이벤트 | 붕괴, 소음, 함정 오작동과 마력 이상 후보 중 일부가 활성화됨 | 방문별 가변 |
| 골렘·장치 | 지정 후보 안에서 위치와 상태가 달라짐 | 방문별 가변 |
| 잔여 구역 | 여러 고정 후보 중 일부가 단서와 함께 노출됨 | 발견·소실 상태는 저장 |
| 다른 수색꾼 흔적 | 발자국, 빈 상자, 버린 가방과 경고 표식으로 나타남 | 방문별 가변 |

다른 수색꾼은 던전 내부에서 직접 조우시키기보다 흔적과 랜덤 이벤트로 표현한다. 등장 빈도와 후보별 확률은 아직 정하지 않는다.

## 방문 시작

새 탐험은 다음 순서로 준비한다.

1. 고정 지도와 현재 영구 던전 상태를 불러온다.
2. 소실·봉쇄된 구역과 획득 완료한 원본을 후보에서 제외한다.
3. 탐험 시드를 정한다.
4. 시드와 구역별 후보를 사용해 문·통로, 아이템, 위험, 골렘·장치와 흔적의 현재 방문 상태를 고른다.
5. 입구와 방의 정체성은 바꾸지 않은 채 탐험을 시작한다.

후보별 가중치, 최소·최대 수량과 정확한 난이도 보정은 원본과 GDD의 데이터 항목으로만 남아 있으며 이번 티켓에서 수치로 확정하지 않는다.

## 귀환과 실패

| 결과 | 방문 상태 처리 |
|---|---|
| 안전 귀환 | 들고 나온 회수품과 확인한 영구 변화를 정산 대상으로 넘기고 거점 진행에 반영함 |
| 부분 성공 | 목표를 놓쳐도 회수품과 정보가 있으면 정상 정산함 |
| 행동 불능·퇴로 상실 | 현재 방문의 미확보 회수품을 잃고 거점으로 돌아감 |

- 안전 귀환 전의 고유 유물과 핵심 기록물은 영구 획득으로 저장하지 않으며 다음 방문 후보에 남긴다.
- 돈, 거점과 이미 확정된 연구 진행은 실패해도 유지한다.
- 거점 진입, 정산 완료와 주요 등록 이후 저장한다.
- 탐험 도중 자유 저장·불러오기는 제공하지 않는다.

실패한 방문에서 새로 확인한 지도 정보까지 보존하는지는 원본과 GDD가 명시하지 않았다. 이 항목은 임의로 확정하지 않는다.

## 잔여 구역

잔여 구역은 고정된 큰 지도 안에 후보로 존재하고, 방문별 단서와 접근 상태를 통해 노출한다.

- 닫힌 문을 적절한 도구로 연다.
- 구석의 균열을 조사해 작은 방이나 우회 통로를 드러낸다.
- 개인 표식과 방향 메모가 지도 밖 공간을 암시한다.
- 잔존 에너지 유실이나 붕괴로 이전에는 보이지 않던 틈이 드러난다.
- 고유 유물 회수 후 한 구역이 닫히면서 다른 후보가 노출될 수 있다.

발견한 잔여 구역은 지도에 기록할 수 있지만, 소멸 진행에 따라 다시 막히거나 사라질 수 있다. 공식 지도에는 주요 공략 루트가 남고, 현재 열린 길과 무너진 길을 구분해 표시한다. 잔여 구역의 정확한 위치는 단서만 얻은 시점에 바로 공개하지 않는다.

단서가 즉시 구역을 여는 열쇠인지 위치를 암시하는 힌트인지는 모든 발견물에 공통으로 확정하지 않는다. 정보 전달은 [`narrative_delivery.md`](narrative_delivery.md), 실제 개방 행동은 관련 도구와 [`harness_engineering.md`](harness_engineering.md)가 담당한다.

## 고유 유물·핵심 기록물 회수 후 전환

고유 유물과 핵심 기록물은 원본이므로 안전 귀환과 등록이 끝나면 이후 방문의 스폰 후보에서 제외한다.

| 시점 | 물품 상태 | 구역 상태 |
|---|---|---|
| 현재 방문에서 발견 | 임시 획득 | 기존 상호작용 유지 |
| 안전 귀환 전 실패 | 획득 미확정, 후보로 복귀 | 영구 변화 없음 |
| 안전 귀환·등록 완료 | 영구 획득 및 등록 | 다음 방문 변화 예약 |
| 다음 방문 이후 | 스폰 후보에서 제외 | 방 소실, 봉쇄 또는 상호작용 감소 중 해당 구역에 맞는 변화 적용 |

회수 후 변화를 갑작스러운 위험 증가로만 표현하지 않는다. 방 일부가 무너지거나 닫히고, 조사 가능한 오브젝트가 줄며, 남은 흔적이 “무언가 빠져나간 자리”처럼 바뀌는 방향을 우선한다. 입구 근처의 반복 가능한 폐품과 일부 잔재는 별도 후보 규칙에 따라 다시 노출될 수 있다.

어떤 물품이 어느 방 변화를 일으키는지와 변화 적용 시점의 세부 조건은 아직 확정하지 않는다.

## 잔존 에너지와 보상 노출

반복 방문에서 새 보물이나 새로운 고유 유물을 생성하지 않는다. 잔존 에너지 유실은 이미 존재하던 폐품, 느슨해진 장치, 응축된 잔재와 숨은 상호작용 대상을 드러내는 설명과 노출 규칙으로 사용한다.

원본 `TBL-022`의 처리 규칙은 다음과 같다.

| 처리 규칙 | 설명 |
|---|---|
| 일정 노출량 유지 | 탐험마다 폐품과 상호작용 오브젝트가 일정 범위 안에서 등장함 |
| 잔존 에너지 유실 | 에너지가 빠져나가며 숨어 있던 물건이나 장치가 드러나는 개연성을 제공함 |
| 보상 감소형 배제 | 시간이 지날수록 보상이 계속 줄어드는 구조는 현재 방향과 맞지 않음 |
| 위험 감소형 배제 | 던전이 죽어간다고 위험이 단순히 줄어드는 구조도 현재 방향과 맞지 않음 |
| 방 소실형 유지 | 고유 유물이나 핵심 기록물을 회수한 구역을 정리하고, 남은 구역을 간단히 닫는 장치로 사용함 |
| 숨은 잔재 노출 | 새 보물을 생성하는 것이 아니라, 기존에 묻혀 있던 것이 드러나는 방식으로 표현함 |

1. 방문 준비 단계에서 잔존 에너지 유실에 따른 노출 후보를 고른다.
2. 일부 폐품, 잔재와 장치를 상호작용 가능한 상태로 만든다.
3. 플레이어가 그중 일부를 회수한다.
4. 원본 물품을 회수한 구역은 다음 방문부터 소실·봉쇄·상호작용 감소 상태를 적용할 수 있다.
5. 던전이 완전히 붕괴되기 전까지 기본 보상 노출량은 정해진 범위 안에서 유지한다.

- 시간이 지날수록 보상이 계속 줄어드는 단순 감소형을 사용하지 않는다.
- 던전이 죽어간다고 위험이 계속 줄어드는 단순 감소형도 사용하지 않는다.
- 한 방문의 노출량이 지나치게 크거나 작아 운이 판단보다 중요해지지 않게 한다.
- 정확한 노출량 범위와 후보 가중치는 후속 밸런스 작업까지 미확정으로 둔다.

## 저장 책임

이 문서는 저장해야 하는 방문 간 결과의 종류만 정한다.

- 던전별 영구 변화 상태
- 방의 개방·붕괴·소실과 조사 상태
- 획득 완료한 고유 유물·핵심 기록물의 제외 결과
- 최초 진행 이벤트와 첫 개방의 완료 여부
- 방문한 방과 확인한 통로의 지도 상태

개별 아이템 플래그와 저장 필드는 [`item_rules.md`](item_rules.md), 발견물 등록과 연구 해설 단계는 [`narrative_delivery.md`](narrative_delivery.md)가 소유한다. 구현용 내부 식별자와 저장 스키마는 이 티켓에서 새로 만들지 않는다.

## 검증 기준

- 연속 방문에서 배치와 위험이 달라도 같은 방임을 알아볼 수 있다.
- 이전 방문에서 배운 지도 지식이 다음 방문의 판단에 도움이 된다.
- 고유 유물과 핵심 기록물이 영구 획득 후 다시 생성되지 않는다.
- 보상 편차가 플레이어 판단보다 운을 크게 만들지 않는다.
- 원본 물품 회수 후의 구역 변화가 던전 복구가 아니라 누적 소멸로 읽힌다.
- 던전 내부에서 다른 수색꾼을 직접 반복 조우시키지 않아도 흔적으로 활동감을 전달한다.
