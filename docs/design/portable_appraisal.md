# 휴대용 감정 최소 규칙 검토안

## 상태와 승인 경계

DEV-0422의 **문서 제안이며 실행 코드·시험 데이터·저장 스키마 9는 변경하지 않는다.** MIG-CHG-054에 범위를 먼저 기록했다. confirmed [아이템](item_rules.md#감정-상태)·[경제](economy_rules.md#비용-항목)·[반복 탐험](repeat_exploration.md#귀환과-실패)·[정보 전달](narrative_delivery.md#기본-정보-전달-흐름), GDD 8-2와 함께 읽고 draft를 단독 구현 기준으로 쓰지 않는다.

**사용자 선택 완료:** [DEC-117](../project/decisions.md#dev-0422-휴대용-감정-방식-선택)에 따라 **횟수 제한 확정 감정 + 필요한 만큼 유료 구매/휴대 수량 선택 + 안전 귀환 시 미사용분 보관**을 채택했다. 같은 물품은 거점에서 다시 감정하지 않는다. 이 방향만 confirmed 아이템·경제 규칙과 GDD에 반영한다. 아래 가격·수량·무게·UI·사용 시점·실패/저장 세부는 여전히 미적용 시험 제안이다. 문서 커밋 승인은 별도로 받는다.

이름은 기존 공식 행위인 [감정](../reference/glossary.md#감정)을 사용한다. 새 상품명·도구 ID·NPC·서사 지식을 만들지 않는다. [감정사의 더 공식적인 판별](../story/04_characters_and_factions.md#감정사와-감정-방식)과 연구자의 해석 역할은 유지한다. 도구의 기능상 감정 상태 판정을 공식 인증이나 연구 지식 해금으로 확대하지 않는다.

## 선택지 비교

| 정보 방식 | 현장에서 얻는 것 | 역할과 부담 |
|---|---|---|
| 횟수 제한 확정 감정 — 사용자 선택 | 물품 하나의 실제 분류·기존 가치 범위·판매/보호/등록 가능 여부 | 한정된 자원으로 운반 판단. 반복 감정 불필요, 거점은 여러 물품을 더 낮은 시험 비용으로 처리 |
| 예비 감정 | 정체를 확정하지 않는 대략 가치 정보 | 거점 확정의 정보 우위 유지. 오차/범위의 정의·별도 임시 정보 상태·거점 재비용이 필요 |

확정 감정의 ‘가치’는 현재 ItemDefinition의 **예상 가치 범위**다. 현장 표시가 정확한 미래 판매액·세후 입금·공식 인증서·숨은 기억 해설을 약속하지 않는다. 판매액은 실제 거래의 가격 데이터와 보호 여부로 정한다. 예비 감정은 이번에 채택하지 않은 비교안이며 오차나 별도 임시 정보 상태를 추가하지 않는다.

| 준비 방식 | 비용과 출정 | 비교할 점 |
|---|---|---|
| 필요한 만큼 유료 구매 — 사용자 선택 | 보유분을 먼저 쓰고 부족분만 확인·구매, 0개 출정 허용 | 현장 확인의 편의에 비용을 쓰는 선택. 돈이 없으면 미확인 상태로 운반해 거점 감정 가능 |
| 기본 무료분 + 추가 구매 | 매 출정 기본 사용분 제공, 더 가져갈 부분만 구매 | 접근성이 높으나 무료분 비축/환금 방지·소비 순서·거점 서비스와의 가격 관계를 별도 검토 |

## 대상과 사용 제안

이하 조건은 DEC-117 방향을 구체화하는 **미적용 구현 제안과 수용 계약**이다. 사용자 방향 선택이 세부 조작·수치의 최종 승인을 뜻하지 않는다.

| 조건 | 처리 |
|---|---|
| 활성 탐험의 가방에 있는 유효한 미확인 물품, 잔량 1 이상 | 선택한 인스턴스 하나를 확정 감정하고 잔량 1개를 동시에 소비 |
| 이미 감정됨·가방 밖/버린 물품·선택 없음·부족 잔량·잘못된 정의 | 거절, 잔량·물품 상태·충전·돈 변화 없음 |
| 같은 ID의 물품 두 개 | 정의 ID가 아니라 실제 선택 대상/가방 변경 여부를 대조. 하나를 감정해도 다른 복사본은 미확인 유지 |
| 보호 고유 유물·핵심 기록물 | 감정은 허용하되 보호·등록 조건 유지. 판매/일반·빠른 버리기로 우회하지 않음 |
| 월드에 놓인 물품·거점 보관품 | 현장 도구 대상에서 제외. 먼저 회수하거나 기존 거점 감정 사용 |
| 탐험 시작 전·종료/결과 화면·타이틀·거점·다른 창의 오래된 명령 | 거절. 출정별 잔량 재지급/시간 재개 없음 |

1. 현재 인벤토리에서 물품을 고른 뒤 ‘감정 도구 1개 사용’과 남을 수량을 보여주고 확인한다. 선택 전에는 숨은 분류/가치/보호 정보를 미리 노출하지 않는다.
2. 기존 DEC-103의 인벤토리 시간 정지를 유지하고, 유효한 확인 시 즉시 처리하는 시험을 제안한다. 별도 작업 시간·확률 실패·피해/소음/충전 소비를 추가하지 않는다. 부상은 기존 이동/조사/회수에 적용하며 이 즉시 명령의 시간을 새로 늘리지 않는다.
3. 사용 직전에 현재 탐험·인벤토리 소유권·정확한 물품 인스턴스·미확인 상태·잔량·확인 내용을 다시 검사한다. 취소·선택 변경·가방 변경·창 닫기·포커스 이탈·다른 메뉴·탐험 종료는 확인 요청을 버린다. 낡은 확인을 새 대상으로 적용하지 않는다.
4. 성공한 한 명령에서 감정 상태·잔량·사용 집계·가방/가치/HUD/의뢰 진척·외부 무게를 함께 갱신한다. 중복 클릭/키 반복은 두 번 쓰지 않는다. 인벤토리만 닫았다 열거나 같은 장면을 재활성화해 보충하지 않는다.
5. 메뉴를 열기 전 진행하던 조사/회수·투척 대기·빠른 버리기의 기존 취소를 유지한다. 감정 때문에 위험 시간만 흐르거나 잠깐 조작이 풀리지 않아야 한다. 감정 도구는 하네스 장착 슬롯·공유 충전·소음 유인물 횟수와 별개다.

## 수량·비용·적재 제안

| 항목 | 구현 비교값 | 근거·한계 |
|---|---|---|
| 휴대 선택 | 0·1·2개, 새 게임/구형 기본 0 | 소수 물품 우선순위 비교, 구매/감정을 의무화하지 않음 |
| 무료분 | 0개 | DEC-117의 유료 구매 방향. 소음 유인물의 기본 무료분을 가져오지 않음 |
| 구매 단가 | 10 | 현행 거점 감정 5와 비교하는 편의 비용. 최종 가격/생계 압박 승인 아님 |
| 총 보유 한도 | 거점+예약/휴대 합계 2개 | 대량 비축 없이 수량 선택과 미사용 보존 시험. 줄여도 재고 삭제/환불 없음 |
| 배정·사용 원가 순서 | 먼저 취득한 보유분부터, 새 구매는 뒤에 추가 | 다른 가격으로 산 물품의 원가를 현재 가격으로 바꾸지 않음 |
| 회수품 슬롯·무게 | 슬롯 0, 남은 도구 개당 0.25 | 기존 도구 방식과 비교. 회수품/판매품/의뢰 실적으로 취급하지 않음 |

보유 수량 S, 희망 휴대 N, 단가 p에서 부족 구매 B=max(N-S,0), 결제 p×B, 구매 후 보유 S+B, 출정 예약 뒤 거점 잔량 S+B-N이다. 구매 후보는 수량·가격·잔액·원가 기록·전체 한도·곱셈/합계 오버플로를 먼저 검증하고 저장 성공 후 확정한다. 0개는 유효하며 음수·소수 수량/가격·미설정/무효 규칙은 거절한다.

구입과 휴대 선택을 한 준비 화면에서 검토한다. 희망 수량은 기억할 수 있지만 사용/실패로 부족해졌으면 다음 출정 전에 비용을 다시 확인한다. 출정 버튼·이어하기가 자동 재구매하지 않으며 0개로 줄여 출정할 수 있다. 구매 후 수량을 줄여도 이미 산 도구와 취득 원가는 거점에 남긴다.

외부 도구 무게 = 남은 소음 유인물 수×유인물 단위 무게 + 남은 감정 도구 수×감정 단위 무게다. 한 도구가 사용될 때 다른 도구 무게를 덮어쓰지 않는다. 비교 예에서 회수품 2.0+유인물 1개 0.25+감정 도구 1개 0.25=2.5로 부담이며, 감정 후 2.25로 정상이다. 실제 감속·소음·HUD가 같은 합계를 사용한다. 무게로 슬롯 한도를 바꾸거나 감정으로 물품 자체 무게를 줄이지 않는다.

## 귀환·실패·정보 보존 제안

| 시점 | 감정 도구·물품 상태 | 돈·저장 |
|---|---|---|
| 준비 확인 취소/구매 저장 실패 | 원래 재고·선택 유지 | 차감 없음 |
| 예약만 저장된 뒤 시작 전 실패/종료 | 배정한 감정 도구와 원가 반환, 유인물도 각자 기존 반환 | 원래 준비 구간 유지, 이미 구매한 돈 환불 없음. 복구 저장 후 한 번 확정 |
| 시작 표식 저장 후 탐험 | 성공한 사용만 잔량 차감, 감정은 해당 런의 해당 인스턴스에만 적용 | 탐험 중 별도 영구 저장 없음 |
| 일반/기존 비상 안전 귀환 정산 | 미사용 도구 반환, 들고 나온 물품의 감정 상태 유지 | 물품 처리·세금·보상·도구 원가/반환·장비/발견·보고·다음 구간을 함께 저장 |
| 실패 | 휴대한 도구의 사용분+미사용분 소실, 미확보 물품과 감정 상태 상실 | 거점에 남긴 도구·기존 돈/연구·영구 장비 보존, 두 소실 항목 중복 집계 금지 |
| 시작된 채 미정산 종료·결과 화면 종료 | 가져간 도구 전량 소실, 실제 사용 횟수 추측 금지 | 기존 시작 후 종료 복구를 따르고 과거 보유금 벌금/소급 감정료 없음 |
| 정산 저장 실패/재시도·저장 직후 종료 | 실패 전 후보 전부 보류, 성공 후 저장된 결과만 읽기 | 반환·판매/세금·보상·감정/보고의 일부만 반영하거나 다시 지급/차감하지 않음 |

현장 확정 뒤에도 해당 물품을 들고 나와야 한다. 판매 가능한 확인품은 기존 귀환 자동 판매와 DEC-116 회수세에 포함되고, 미확인/보호/가격 미설정품은 기존 보관 경로를 따른다. 감정 행동 자체는 세금·판매·의뢰 보상을 발생시키지 않는다. 현장 확정된 일반 폐품은 기존 의뢰의 가방 실적 조건을 충족할 수 있고 버리면 다시 빠진다. 보상은 안전 귀환 결과로 다시 판정하며 잔재·원본·도구는 실적에 넣지 않는다.

이미 감정된 물품을 거점에서 다시 감정하거나 재비용을 청구하지 않는다. 보호 원본의 감정은 등록/해설/영구 스폰 제외를 대신하지 않는다. 실패한 뒤 같은 정의의 새 물품을 만나도 이전 감정을 자동 공유하지 않는다. 플레이어가 본 정보를 기억하는 것과 게임의 영구 연구 진행을 구분한다.

## 비용 보고와 수치 예

현재 DEC-114의 식을 도구 종류별 취득 원가에 확장하는 제안이다. 감정 도구를 사용하며 다시 현금을 결제하지 않고, 현장 감정에 기존 거점 감정료를 중복 청구하지 않는다.

    수입 = 이번 판매 + 기간 거점 판매 + 의뢰 보상
    손익 = 수입 - 회수세 - 실제 거점 감정료 - 실제 수리비
         - 유인물 사용/미사용 소실 원가 - 감정 도구 사용/미사용 소실 원가
    현금 변화 = 수입 - 회수세 - 거점 서비스 지불
              - 새 유인물 구매 - 새 감정 도구 구매 - 영구 개선 구매
    이번 정산 입금 = 이번 판매 - 이번 판매 회수세 + 의뢰 보상

수치는 비교용 **기대 계산**이며 게임 실행 결과가 아니다. 각 예의 기간 시작 돈은 100, 새 감정 도구 단가 10·기존 회수세 시험값 10%를 사용하고 별도 기재 없는 거래/도구 원가는 0이다. 판매40/30은 독립적으로 준비한 회수품 총액이지 감정이 항상 그 수익을 만든다는 뜻이 아니다.

| ID | 조건 | 감정 사용 원가 | 감정 미사용 소실 원가 | 손익 | 현금 변화 | 기말 돈 | 기말 감정 재고 원가 | 정산 입금 |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| P01 | 새 2개 구매·1개 사용·생환, 판매40+보상10 | 10 | 0 | +36 | +26 | 126 | 10 | 46 |
| P02 | 기존 원가10 한 개 사용·생환, 새 구매0·판매30 | 10 | 0 | +17 | +27 | 127 | 0 | 27 |
| P03 | 새 2개 구매·1개 사용 후 실패 | 10 | 10 | -20 | -20 | 80 | 0 | 0 |
| P04 | 기존 원가8·10 두 개 휴대·앞 1개 사용 후 실패 | 8 | 10 | -18 | 0 | 100 | 0 | 0 |
| P05 | 새 1개 구매·미사용 생환, 판매0 | 0 | 0 | 0 | -10 | 90 | 10 | 0 |
| P06 | 새 2개 구매·예약 반환 후 0개로 빈손 출정/정산 | 0 | 0 | 0 | -20 | 80 | 20 | 0 |
| P07 | 기존 원가8·10 중 앞 1개만 휴대/사용, 판매40 | 8 | 0 | +28 | +36 | 136 | 10 | 36 |
| P08 | 새 감정1개/유인물2개를20에 구매·각1개 사용, 판매40+보상10 | 10 | 0 | +31 | +26 | 126 | 0 | 46 |
| P09 | 돈100·도구0으로 빈손 출정/귀환 | 0 | 0 | 0 | 0 | 100 | 0 | 0 |
| P10 | 새 2개 구매·시작 후 미정산 종료 | 0 | 20 | -20 | -20 | 80 | 0 | 0 |

P08의 유인물은 유료분 원가5를 한 개 사용하고 한 개 원가5를 반환한 계산 예다. 무료분을 사용한 것으로 바꾸어 읽지 않는다. P10의 사용 원가0은 실제 사용하지 않았다는 관찰이 아니라 **사용 횟수를 모르는 중단 보고의 분류**다. 총 휴대 취득 원가20을 소실로 한 번만 기록한다.

원가가 모두 알려졌으면 **손익-현금 변화 = 영구 개선 구매액 + 모든 유료 도구 기말 재고 원가 - 기초 재고 원가**가 유지돼야 한다. 구형 유인물 원가 미기록은 그대로 보존하고 정확한 손익을 보류한다. 새 감정 도구를 핑계로 알 수 없는 과거 단가를 0이나 현재 가격으로 채우지 않는다. 보고에는 두 종류의 구매/사용/반환/소실을 구분하고 영구 투자는 기존 별도 표시다.

## 저장·구형 전환 수용 계약

새 클래스·상품 ID·필드명·스키마 번호는 다음 구현 착수의 MIG-CHG에서 정한다. 지금은 스키마 9·거점 13필드를 유지한다.

- 구매·선택, 도구 종류별 거점 재고/취득 원가, 예약/휴대 수량과 원가, 사용/반환/소실 결과 및 기간/최근 보고를 서로 대조할 수 있어야 한다. 실제 런 물품/타이머 자유 저장은 추가하지 않는다.
- 출정의 비활성 구성 검증 → 두 도구 배정 예약 저장 → 탐험 초기화 → 시작 표식 저장 → 조작 활성 순서를 유지한다. 어느 한 도구만 예약하거나 반환하지 않는다. 시작 표식 뒤 조작이 열리기 전 종료도 기존 시작 기록 규칙을 따른다.
- 구형 1~9에는 휴대용 감정 구매/사용이 없으므로 **재고0·선택0·새 종류의 과거 비용0**으로 보완한다. 기존 유인물 원가/partial·세금 도입 전 기록·최근 의뢰 보상·물품 감정 상태·예약/시작 복구를 그대로 유지한다.
- 읽기만으로 파일을 쓰지 않고 정상 거래/필요한 복구 저장 성공 시 전환한다. 신형 필드 누락·구형/신형 혼합·잘못된 수량/종류·원가 합계/남은 재고 불일치·미지원 버전은 추측 보정하지 않고 보존/오류로 처리한다.
- 구형에 새 도구 원가 미기록을 발명하지 않는다. 신형에서 새 구매 원가가 없으면 오류다. 미지원 콘텐츠·보호 플래그·등록/보관 중복의 기존 검증도 유지한다.
- 모든 금액은 기존 int64 범위와 정확한 정수 문자열 계약, 수량은 상한 있는 정수, 무게는 유한한 비음수 데이터로 검증한다. 후보 합계/현금/원가 넘침과 기존 파일 크기 한도를 저장 전에 확인한다.
- 저장 실패는 기존 지갑/재고/감정·선택·보고를 보존한다. 복구 저장 실패 동안 준비/서비스/출정을 막고 재시도하며, 성공한 출정 ID·구매·정산·반환을 중복 반영하지 않는다.

## 후속 구현 수용 기준

다음은 **DEV-0423 — 휴대용 감정 준비·사용·정산 연결**의 인계 범위다. DEC-117·confirmed 규칙을 기준으로 이 문서의 시험 제안을 함께 검토한다. DEV-0422 결과를 검증하고 사용자 승인으로 한 커밋에 분리한 뒤 다음 작업을 시작한다.

3. 보호 원본·가격 미설정·일반 폐품/잔재를 구별하고 안전 귀환 전 등록 금지·실패 후 재등장/미확인·거점 재감정 금지·기존 판매 보호/의뢰 실적을 확인한다.
4. 유인물과 함께 휴대한 무게/부담·감속·발소리/HUD, 두 종류 각각 사용 후 합계, 거점 미휴대 재고 보존·다른 단가의 먼저 취득한 원가, P01~P10과 모든 재고의 손익/현금 등식을 검사한다.
5. 구매·선택·예약·시작·정산·복구의 저장 실패/재시도와 저장 직전/직후 외부 종료·새 프로세스 이어하기를 검사한다. 구형 1~9의 정상/예약/시작/최근 보고·원가 미기록·손상/미지원도 포함한다.
6. 실제 인벤토리에서 마우스·키보드로 선택/확정/취소하고, 1152×648·1600×900에서 준비 견적·긴 금액·잔량0·보호/미확인·오류·결과/최근 보고를 검사한다. 실제 행동과 준비한 경계 사례를 구분해 기록한다.
7. 기존 전체 자동 검사를 유지하고 실제 소스 해시/실행 결과를 남긴다. UI 표시·수치 계산 통과를 사람의 운반 판단·도구 가치·가격 적절성 평가로 바꾸지 않는다.
