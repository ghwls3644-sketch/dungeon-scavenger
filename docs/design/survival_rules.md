# 생존 상태와 퇴로 규칙 검토안

## 적용 상태

**이 문서는 DEV-0318의 검토안과 DEV-0319의 제한된 시험 적용 기록이며 최종 설계 확정이 아니다.** `draft`이므로 단독 구현 기준으로 사용하지 않는다. 기존 기준의 요구·제안과 아래의 실제 시험 적용 범위를 구분한다. 구현할 때는 GDD·confirmed Design·사용자가 검토한 해당 작업 범위를 함께 확인하고, 사용할 시험 값과 영향받는 기존 동작을 이관 변경 기록에 먼저 남긴다. 이 문서를 커밋하거나 다음 작업으로 넘어가는 것만으로 최종 피해·회복·비상 탈출 수치가 확정되지는 않는다.

현재 구현과 후속 작업 순서는 [G3 검토](../project/g3_exploration_review.md#dev-0319-건강부상-시험-적용)와 [개발 인계](../project/development_handoff.md#dev-0319--건강부상-상태와-hud)가 소유한다. 여기서는 상태·조건·행동 효과를 다룬다. 세계관의 사고 책임, 치료자·구조자의 정체, 고유 장비·물품명은 추가하지 않는다.

## 기존 기준에서 정한 요구

| 항목 | 지켜야 할 요구 | 근거 |
|---|---|---|
| 건강 | 피해와 행동 불능을 판단하며 세부 수치는 단순화 | [GDD 6-2](../GDD.md#6-2-플레이어-상태) |
| 부상 | 이동·상호작용 효율에 일시적인 불이익 | [GDD 6-2](../GDD.md#6-2-플레이어-상태) |
| 사전 단서·대응 | 큰 위험 전에 시각 또는 청각 단서를 제공하고 관찰·회피·도구·퇴각을 우선 | [GDD 9-1~9-5](../GDD.md#9-1-위험-유형), [Story 방향](../story/00_core_pillars.md#전투보다-회피와-탈출이-중요한-이유) |
| 행동 불능 | 현재 탐험의 미확보 회수품을 잃고 거점 복귀 | [반복 탐험의 귀환·실패](repeat_exploration.md#귀환과-실패) |
| 퇴로 상실 | 제한 시간 또는 비상 탈출 실패 시 행동 불능과 동일 처리 | [GDD 4-3](../GDD.md#4-3-성공과-실패) |
| 재기 | 기존 돈·거점·연구 진행 보존, 영구 장비 유지·손상, 최소 재출정 수단 보장 | [경제의 실패 손실·안전망](economy_rules.md#실패-손실과-재기-안전망), DEC-105 |
| UI·정지 | 건강·부상과 현재 위험을 HUD에 표시하고 가방·지도에서 탐험 시간 정지 | [GDD 12-3~12-4](../GDD.md#12-3-hud-우선순위), DEC-103 |

건강과 부상의 역할이 정해졌다는 사실은 체력 총량, 위험별 피해량, 부상 지속 시간, 자동 회복, 치료비나 비상 탈출 비용까지 정해졌다는 뜻이 아니다. [열린 질문](../project/open_questions.md#생존-규칙-검토-경계)에서 해당 공백을 추적한다. `Q-014`는 허가·사회적 사고 책임에 관한 질문이며 피해·치료 수치의 근거로 대신 사용하지 않는다.

## 건강과 부상의 최소 시제품 제안

### 서로 다른 상태로 관리

건강 잔량은 행동 불능까지 남은 여유, 부상은 일정 시간의 행동 효율 저하로 분리하는 방향을 제안한다. 화면에서는 숫자만으로 부상 여부를 추측하게 하지 않고 건강과 부상을 함께 표시한다. 다음 표는 **DEV-0318의 제안**이며, DEV-0319에서 상태·이동 부분을 아래 범위로 시험 적용했다. 상호작용 효과는 후속이다.

| 입력 | 건강 | 부상 | 결과 |
|---|---|---|---|
| 새 출정 시작 | 출정 기준값으로 시작 | 없음 | 현재 탐험의 새 상태 |
| 일반 피해 후 건강이 남음 | 피해량만큼 감소 | 부상 시작 또는 남은 시간 갱신 | 탐험 계속, 효과·해제까지 남은 시간 표시 |
| 일반 피해로 건강 소진 | 0 | 더 이상 행동 효과를 갱신하지 않음 | 행동 불능 신호를 한 번만 전달 |
| 포착·중대 붕괴 등 별도 행동 불능 입력 | 잔량과 무관하게 0 | 종료 | 사전 경고를 거친 기존 포착·붕괴 실패 유지 |
| 부상 시간 만료 | 그대로 유지 | 해제 | 이동·상호작용 효율만 정상으로 복원 |
| 안전 귀환 또는 다른 원인의 실패 | 더 이상 변경하지 않음 | 시간 정지·해제 처리 후 폐기 | 결과·정산은 탐험 종료 계층이 담당 |

최소 비교에는 **건강 2, 일반 피해 1**처럼 한 번의 피해에서 살아남고 다음 피해에 행동 불능이 되는 작은 시험 값을 제안했다. DEV-0319에서 함정 피해에 시험 적용했으며 확정 밸런스는 아니다. 피해량·지속 시간·효율 계수는 데이터 자원으로 분리하고 유효 범위·복사본을 검사한다. 재생·치료 아이템·던전 내 자동 체력 회복은 이 최소 제안에 넣지 않는다. 새 출정 초기화는 임시 실행 정책이며 제품의 치료·재기 비용 결정과 구분한다.

### 위험 입력의 역할

첫 일반 피해 후보는 기존 잔여 구역의 **함정 오작동**이다. 새 적·무기·방을 만들지 않고 이미 존재하는 경고·작동 주기를 이용해 부상 후 대응을 비교할 수 있기 때문이다. DEV-0318까지 함정은 한 번 맞으면 바로 탐험에 실패했다. DEV-0319에서 이를 일반 피해로 바꾸면서 관련 실패 검사·안내 문구·통합 근거도 함께 갱신했다.

- 함정의 같은 작동 주기·같은 플레이어는 한 번만 피해를 받는다. 작동 중 나갔다 다시 들어와도 추가 피해를 주지 않는다. 다음 작동 주기는 다시 피해를 줄 수 있다. 이는 기존 함정의 주기별 중복 통지 방지 계약을 이어 쓰는 제안이다.
- 골렘의 연속 접촉 경고 종료와 중대 붕괴는 기존 행동 불능 입력으로 유지하는 방향을 권장한다. 건강 잔량을 도입했다는 이유만으로 모든 기존 위험을 여러 번 견디게 바꾸지 않는다.
- 위험 소유자는 사전 경고·판정·중복 방지를 담당하고 생존 상태 소유자는 유효한 피해·부상·행동 불능을 처리한다. 실패 때 물품을 지우고 결과를 만드는 책임은 기존 탐험 종료 계층에 둔다.
- 한 번의 물리 틱에서 서로 다른 위험이 겹쳐도 행동 불능·탐험 종료는 한 번이다. 한 번 끝난 탐험에서 귀환·피해·비상 방전 등의 늦은 통지가 결과를 바꾸면 안 된다. 안전 귀환과 실패가 같은 틱에 요청되면 기존처럼 먼저 수락한 종료 결과를 유지하는 방향을 권장한다.
- 피해 경고 없이 주기만으로 건강을 감소시키거나, 부상만으로 새 소음·경보를 만들거나, 건강을 공격 자원으로 사용하는 전투는 추가하지 않는다.

### 행동 효율과 조작

이동은 `기본 속도 × 기존 적재 계수 × 부상 계수`로 분리하는 방향을 제안한다. 짐 버리기는 적재 부분만 개선하고, 부상 해제는 부상 부분만 복원한다. 부상 때문에 무게 단계나 물품 데이터가 바뀌면 안 된다. 이동 소음은 기존처럼 실제 이동과 적재 규칙에서 계산하며, 부상에 임의의 별도 경보를 붙이지 않는다. 부상 중 짐을 버렸다고 반드시 모든 추적에서 탈출할 수 있다고 안내하지 않는다.

상호작용은 현재 E 입력 즉시 처리와 별개의 변경이다. 먼저 건강·부상 상태와 이동·HUD를 구현하고, 그다음 **조사·회수의 작업 시간**을 한정해서 비교하는 방향을 권장한다. 일반/부상 상태의 작업 시간, 시작 입력, 진행 표시, 취소와 완료 시점의 대상 재검증을 해당 작업에서 함께 정한다. 문 개폐·입구 귀환·Q 대응·메뉴·G 빠른 버리기를 일괄 지연시키지 않는다. 이 구분은 GDD의 부상 요구를 삭제하는 것이 아니며 상호작용 효과까지 구현하기 전에는 건강·부상 전체 완료로 보고하지 않는다.

작업 시간이 생길 때는 대상 이탈·삭제·대상 변경·가방/지도 열기·탐험 종료를 취소 조건으로 다룬다. 취소한 회수는 물품을 추가하거나 원본을 제거하지 않는다. 완료 순간 슬롯·대상·탐험 상태를 다시 확인하고 같은 물품을 중복 지급하지 않는다. 시간·계수·취소 규칙은 구현 착수 때 검토할 계약이며 현재 조작은 이번 문서 작업에서 변경하지 않는다.

### 일시정지·회복·표시

- 가방·지도에서는 부상 시간·진행 중 작업·위험 입력이 탐험과 함께 멈춘다. 메뉴를 닫은 뒤 중단된 시간만큼 몰아서 피해를 주거나 회복시키지 않는다.
- Q 방전·안정화는 위험의 행동을 바꾸며 건강 회복·치료를 겸하지 않는다. 충전과 도구 재고는 별도 소유권을 유지한다.
- 건강·부상 표시, 위험의 사전 경고와 적재 단계는 서로 대체하지 않는다. 접촉 경고가 떠도 현재 건강·부상·적재 안내를 가리지 않도록 실제 화면에서 확인한다.
- 부상 해제와 체력 회복을 다른 문구로 안내한다. 효과 해제만 일어났는데 건강 잔량까지 회복된 것으로 표시하지 않는다.
- 귀환/실패 때 입력·시간을 정리하고 결과에 필요한 원인만 넘긴다. 이 제안만으로 탐험 중 저장·거점 치료비·장비 손상·영구 부상 필드를 추가하지 않는다.

## DEV-0319 시험 적용 범위

GDD·confirmed Design의 위 요구와 `MIG-CHG-028`에 기록한 범위로 현재 출정에만 적용한다. [시험 데이터](../../src/data/prototype_survival.tres)는 건강 2·함정 피해 1·부상 6초·부상 이동 계수 0.9다. 건강은 0 미만으로 내려가지 않으며, 첫 피해 뒤 부상이 시작되고 다음 피해로 건강이 소진되면 실패한다. 부상 재발은 남은 시간만 6초로 갱신한다. 한 함정 작동 주기의 재진입은 추가 피해를 주지 않는다.

이동은 기본 속도×적재 계수×부상 계수다. 가방·지도에서 시간이 정지하고, Q와 짐 버리기는 건강·부상을 치료하지 않는다. 6초가 지나면 이동 효율만 돌아오며 건강 1/2는 유지된다. 화면 맨 위에 건강·부상 시간/이동 효율을 표시하고, 해제 뒤에도 건강 미회복을 안내한다. 적재 HUD는 두 계수를 반영한 실제 이동 비율을 표시한다.

골렘 포착·붕괴는 기존 사전 경고를 거쳐 건강 잔량과 무관하게 행동 불능으로 연결한다. 끝난 출정은 피해·시간·재시작을 받지 않으며 새 출정에서만 새 건강 2·부상 없음으로 시작한다. 결과는 기존 손실·정산을 사용하고 함정 피해로 건강이 소진되었다는 원인을 표시한다. 새 저장 필드·치료비·수리비는 추가하지 않는다.

조사·회수는 아직 즉시 E 처리이며 부상의 상호작용 효과는 **DEV-0320 — 부상의 조사·회수 시간**에서 다룬다. 퇴로 변화·비상 탈출, 최종 피해/회복/시간/계수와 사람 평가도 후속이다. `draft` 상태와 Q-019~Q-021은 유지한다.

## 퇴로 상실과 비상 탈출의 구현 전 경계

입구 방향 화살표나 지도에 기록된 막힌 통로 하나만으로 퇴로 상실을 판정하지 않는다. 현재 지도 기록은 마지막 관찰 정보이며 실제 도달 가능성을 보증하지 않는다. 퇴로 상실에는 영향을 받는 길, 실제 길을 막는 사건, 사전 경고와 대체 경로의 존재를 판정하는 소유자가 필요하다. 미관찰 변화가 지도에 자동 공개되거나 닫힌 시험 문 하나로 즉시 실패해서는 안 된다.

첫 비교는 무작위 전역 폐쇄보다 **알려진 통로 하나의 경고·차단·우회**를 별도 시험 공간에서 다루는 방향을 권장한다. 이는 후보 범위이며 새 퇴로 변화 이벤트나 비상 출구가 현재 구현되어 있다는 뜻이 아니다. 같은 입구로 돌아오는 기본 성공 경로를 보존하고, 실제 대체 길·경고 전달·메뉴 정지·귀환 가능 여부를 먼저 확인한다.

다음 항목은 [Q-021](../project/open_questions.md#질문-목록)에서 구현 전 결정 대상으로 남긴다.

- 어떤 사건과 실제 통로 조건이 퇴로 상실을 확정하는가? 마지막 관찰 정보와 실제 경로를 어떻게 구분하는가?
- 제한 시간은 언제 시작·취소되며 가방·지도 정지와 어떻게 일치하는가? 미확정 시간을 임의의 런 제한 시간으로 사용하지 않는다.
- 비상 탈출은 어디서 어떤 입력·자원·지연으로 시도하는가? 자원이 없을 때의 대응은 무엇인가?
- 비상 탈출 **성공** 때 들고 있던 회수품과 방문 정보는 어떻게 처리하는가? 기존 문서는 실패 처리만 명시하므로 성공을 자동으로 정상 귀환 또는 전량 손실로 해석하지 않는다.

제한 시간 만료나 비상 탈출 실패의 손실은 기존 행동 불능 처리로 연결한다. 별도의 경제 보상·벌금·보험·사망 서사를 만들지 않는다. 성공 조건·비용·회수품 처리와 `Q-014`의 사회적 사고 책임은 별개다.

## 후속 구현 검증 계약

| 대상 | 실제로 확인할 사례 |
|---|---|
| 건강·부상 구분 | 첫 일반 피해에서 생존, 같은 주기 중복 피해 차단, 다음 피해의 행동 불능, 부상 해제 후 건강 잔량 유지 |
| 기존 위험 | 골렘 경고/취소/포착·붕괴 실패 유지, 일반 피해와 동시 발생해도 한 번만 결과 생성, 원인 표시와 미확인 정보 보호 |
| 이동·적재 | 정상/부담/과적 각각에서 부상 전후 실제 이동 비교, 짐 버리기와 부상 해제의 독립 복원, 실제 이동 소음의 기존 계산 유지 |
| 상호작용 | 실제 입력·진행·대상 이탈·재검증·취소, 가득 찬 가방·삭제된 대상·중복 완료에도 잘못된 회수 없음 |
| 수명·거점 | 가방/지도 정지, 종료 뒤 변화 차단, 새 출정 초기화, 현재 손실과 기존 보유분 보존, 저장 스키마·사용자 파일 보호 |
| 퇴로 | 열린 대체 길이 있을 때 오판 금지, 사전 경고·실제 차단·재관찰, 제한 시간과 비상 탈출의 성공/실패를 결정된 처리에 맞게 비교 |
| 화면·사람 평가 | 건강·부상·적재·위험 안내가 겹치지 않는 실제 화면, 부상과 회복의 차이를 이해하는지 후속 사람 확인 |

자동 검사는 선택한 시험 규칙의 동작을 입증한다. 경고가 충분한지, 부상 불이익이 납득되는지, 회복 비용과 비상 탈출이 공정한지는 별도의 사람 평가다. `Q-004`·`Q-005`를 이 문서나 자동 검사로 해결하지 않는다.
