# 아이템 규칙

## 목적

아이템 분류가 데이터, 저장, 거래, UI에서 어떻게 작동하는지 관리한다.

## 포함 범위

- 아이템 분류와 내부 식별자 원칙
- 감정 전후 상태와 판매 가능 여부
- 고유 유물·기록물의 획득 및 등록 플래그
- 반복 스폰, 저장 데이터, UI 구분, 판매 차단

## 제외 범위

- 아이템의 세계관상 의미와 반복 등장 개연성
- 사용자 표시 명칭의 정의
- 가격, 감정 비용, 수익 계산
- 방문별 방·구역 상태와 아이템의 실제 배치
- 발견물 등록 후 해설·재열람과 NPC 반응 조건

## 데이터 경계와 식별자 원칙

- 표시 이름과 코드에서 사용하는 안정적 ID를 분리한다.
- 저장과 원본성 판정에는 표시 이름이 아니라 안정적 ID를 사용한다.
- `ItemDefinition`은 안정적 ID, 분류, 무게, 슬롯 크기, 가치 범위와 판매 보호 여부를 가진다.
- 구역별 후보, 가중치와 최소·최대 노출량은 `LootTable` 책임으로 분리한다.
- 고유 유물·핵심 기록물의 원본 획득, 등록과 스폰 제외 상태는 `UniquePickupState`로 관리한다.
- 밸런스 수치와 콘텐츠 값은 코드에 직접 고정하지 않는다.

실제 코드 ID, 저장 키와 번역 키는 구현 단계 전에 확정하지 않는다. 이 문서는 필요한 정보 종류와 상태 관계만 정한다.

## 분류와 기본 처리

[`잔류물`](../reference/glossary.md#잔류물)은 길드·행정이 회수 가능한 물품 전체를 가리키는 상위 표현이다. 각 분류의 세계관상 의미와 원본성은 [`../story/05_items_and_discoveries.md#아이템-분류의-서사-의미`](../story/05_items_and_discoveries.md#아이템-분류의-서사-의미)를 따르며, 실제 시스템 분류와 기본 처리는 다음과 같다.

| 분류 | 반복 | 기본 처리 | UI 기준색 |
|---|---:|---|---|
| 미확인 물품 | 실제 분류에 따름 | 감정 전 가치·분류 비공개 | 회색 |
| 폐품 | 반복 | 판매, 수리·제작 재료 | 갈색 |
| 잔재 | 낮은 확률 | 감정 후 판매·연구·수집 | 파란색 |
| 고유 유물 | 1회 | 판매 불가, 등록·정보·보상 | 보라색 |
| 핵심 기록물 | 1회 | 판매 불가, 연구자 보관 | 초록색 |

미확인 물품은 독립된 최종 종류가 아니라 실제 분류를 아직 알지 못하는 감정 전 상태다. 따라서 반복 가능 여부와 판매 보호는 감정 여부로 바뀌지 않고 그 물품의 실제 분류를 따른다.

원본 `TBL-015`의 분류별 처리 방식은 다음과 같다.

| 분류 | 처리 방식 |
|---|---|
| 폐품 | 판매 가능. 제작, 수리, 재료로 사용 가능 |
| 잔재 | 감정 후 판매하거나 수집, 연구 의뢰에 사용 가능 |
| 고유 유물 | 판매 불가. 관련 NPC에게 가져가 정보, 보상, 수집 등록을 얻음 |
| 핵심 기록물 | 판매 불가. 특정 연구자나 기록 장치에 보관해 목록을 채움 |
| 미확인 물품 | 감정 전에는 정확한 가치와 분류를 알 수 없음 |

제작·수리 시스템의 세부 소비 방식, 연구 의뢰 조건과 보상은 이 문서에서 새로 확정하지 않는다.

## 감정 상태

원본 `TBL-011`이 제시한 두 감정 방식은 다음과 같다.

| 감정 방식 | 특징 |
|---|---|
| 감정사에게 맡기기 | 여러 개의 미확인 물품을 한 번에 맡길 수 있음. 비용이나 시간이 들 수 있음 |
| 휴대용 감정 아이템 | 탐험 중 바로 확인 가능. 대신 사용 횟수, 비용, 정확도 제한을 둘 수 있음 |

현재 GDD는 거점 감정의 비용과 휴대용 감정의 제한 횟수 또는 낮은 정확도를 명시한다. 감정 시간과 구체적인 제한 조합은 아직 확정하지 않는다.

| 상태 | 확인 가능한 정보 | 다음 처리 |
|---|---|---|
| 미확인 | 무게, 외형, 위험 표시 | 거점 감정 또는 휴대용 감정 도구 사용 |
| 휴대용 감정 결과 | 도구의 사용 횟수·정확도 제한 안에서 공개된 정보 | 정확도 규칙에 따라 현장 판단 또는 거점 확정 감정 |
| 확정 감정 | 실제 분류, 가치와 해당 처리 가능 여부 | 판매·연구·수집·등록 등 분류별 처리 |

- 거점 감정사는 여러 미확인 물품을 비용과 함께 확정 감정한다.
- 휴대용 감정 도구는 던전 안에서 바로 사용할 수 있지만 사용 횟수 또는 정확도에 제한을 둔다.
- 감정 전에도 무게·외형·위험 표시는 숨기지 않는다.
- 플레이어 성장에 따라 감정 전 가치 범위를 더 정확히 추정할 수 있다.
- 잔재의 기억 표현은 짧은 텍스트를 기본으로 하며 문체는 [`../story/07_tone_and_writing_guide.md`](../story/07_tone_and_writing_guide.md)가 소유한다.

휴대용 감정의 정확한 사용 횟수, 오차 방식과 확정 감정까지 걸리는 시간은 아직 수치로 정하지 않는다. 거점·휴대용 감정 비용은 [`economy_rules.md`](economy_rules.md)가 소유한다.

## 스폰과 반복 가능 여부

| 분류·상태 | 후보 포함 규칙 |
|---|---|
| 미확인 물품 | 실제 분류의 반복·1회성 규칙을 따름 |
| 폐품 | 구역별 후보 안에서 반복 가능 |
| 잔재 | 구역별 후보 안에서 낮은 빈도로 반복 가능 |
| 고유 유물 | 원본 획득·등록 전까지만 후보에 포함하는 1회성 |
| 핵심 기록물 | 원본 획득·등록 전까지만 후보에 포함하는 1회성 |

- 기록실에서는 기록물, 경비실에서는 장치 부품, 폐숙소에서는 생활 흔적처럼 구역별 후보 풀을 둔다.
- 후보 풀 안의 실제 아이템과 위치는 탐험 시드로 결정한다.
- 방문 준비 단계에서는 영구 획득·등록 플래그를 확인해 이미 확보한 원본을 후보에서 제외한다.
- 분류별 후보 가능 여부는 이 문서, 방문별 배치와 노출량은 [`repeat_exploration.md`](repeat_exploration.md)가 소유한다.

정확한 후보 가중치, 수량, 잔재 등장 확률과 방별 콘텐츠 목록은 후속 밸런스·콘텐츠 작업까지 미확정으로 둔다.

## 획득·등록·스폰 제외 상태

| 시점 | 물품 상태 | 저장·후속 후보 처리 |
|---|---|---|
| 던전에서 발견 | 현재 탐험의 임시 획득 | 영구 획득으로 저장하지 않음 |
| 안전 귀환 전 실패 | 임시 획득 상실 | 고유 유물·기록물은 다음 탐험 후보에 남음 |
| 안전 귀환·정산 | 회수품 확보 | 일반 회수품은 거점 처리 대상으로 넘김 |
| 원본 등록 완료 | 고유 유물·핵심 기록물의 영구 획득·등록 | 안정적 ID를 저장하고 이후 스폰 후보에서 제외 |

고유 유물은 수집·정보·보상 등록으로, 핵심 기록물은 연구자 또는 기록 장치 보관으로 연결한다. 실제 담당자 라우팅, 해설 해금과 재열람은 [`narrative_delivery.md`](narrative_delivery.md)가 소유한다.

## 판매·폐기 보호

원본 `TBL-019`의 판매 가능 여부는 다음과 같다.

| 분류 | 판매 가능 여부 |
|---|---|
| 폐품 | 가능 |
| 일반 잔재 | 가능 또는 연구 의뢰 가능 |
| 고유 유물 | 판매 불가 |
| 핵심 기록물 | 판매 불가 |
| 특정 의뢰품 | 판매 불가 |

- 고유 유물, 핵심 기록물과 보호 중인 특정 의뢰품은 상점 판매 대상에서 제외한다.
- 보호 물품은 추적 중 사용하는 빠른 버리기 대상에서도 제외한다.
- 일반 버리기는 실행 전에 확인을 표시하되, 빠른 버리기는 가장 최근 선택한 일반 회수품에만 적용한다.
- 미확인 물품의 실제 분류가 보호 대상이면 감정 전 판매·폐기로 보호를 우회할 수 없어야 한다.
- 인벤토리에서는 판매 보호 여부를 가치·무게·분류와 함께 비교할 수 있게 한다.

미확인 물품의 판매 허용 여부와 가격 불이익, 의뢰 종료 후 보호 해제 조건은 아직 확정하지 않는다. 가격과 손익은 [`economy_rules.md`](economy_rules.md)가 소유한다.

## UI 분류와 접근성

원본 `TBL-014`의 UI 분류 색상을 다음과 같이 이관한다.

| 분류 | 테두리 색 후보 | 의미 |
|---|---|---|
| 미확인 물품 | 회색 | 아직 정체를 모르는 물건 |
| 폐품 | 갈색 | 흔한 물리적 잡동사니, 재료, 판매품 |
| 잔재 | 파란색 | 마력과 기억 흔적이 남은 물건 또는 현상 |
| 고유 유물 | 보라색 | 단 하나뿐인 원본 수집품 |
| 핵심 기록물 | 초록색 | 연구자에게 보관하거나 기록 목록을 채우는 물건 |

- 감정 전에는 회색으로 표시하고, 감정 후에는 실제 분류의 기준색으로 바꾼다.
- 분류는 색상만으로 구분하지 않고 아이콘, 명칭, 문자 표기와 테두리 표현을 함께 사용한다.
- 미확인 상태에서는 가치와 실제 분류를 숨기되 무게·외형·위험 정보는 표시한다.
- 고유 유물·기록물은 가격 대신 등록·정보 보상을 표시한다.
- 일반 회수품은 가격뿐 아니라 무게 대비 가치 비교를 제공한다.
- 의뢰품과 고유 물품 획득은 일반 회수품과 구분해 알린다.

아이콘 모양, 문자 약어, 테두리 두께와 화면 배치는 아직 정하지 않는다. UI는 보호 규칙을 표시할 뿐 판매·폐기 가능 여부를 직접 소유하지 않는다.

## 저장 데이터

아이템 관련 저장은 최소한 다음 정보를 보존한다.

- 저장 스키마 버전
- 정산 후 거점에 보유한 물품의 안정적 ID와 감정·보호 상태
- 획득·등록 완료한 1회성 물품의 안정적 ID
- 고유 유물·핵심 기록물의 획득, 등록과 스폰 제외 상태

현재 탐험의 임시 획득과 감정 상태는 `RunState`에서 관리한다. 현재 설계에서는 거점 진입, 정산 완료와 주요 등록·구매 후 자동 저장하며 탐험 도중 자유 저장·불러오기는 제공하지 않으므로, 이 임시 상태를 영구 저장 대상으로 확정하지 않는다. 저장 스키마의 실제 필드명과 버전 값은 구현 단계에서 정하며 이 문서에서 새 키를 만들지 않는다.

## 검증 기준

- 감정 전에는 가치와 실제 분류가 숨겨지고 무게·외형·위험 정보는 유지된다.
- 분류를 색상 없이도 아이콘·명칭·문자 표기로 구분할 수 있다.
- 고유 유물·핵심 기록물·보호 의뢰품을 상점에 판매할 수 없다.
- 보호 물품이 빠른 버리기 대상에 들어가지 않는다.
- 고유 유물과 핵심 기록물이 영구 등록 후 다시 스폰되지 않는다.
- 실패한 탐험에서 안전 귀환하지 못한 원본은 영구 획득 처리되지 않는다.
- 표시 이름이 바뀌어도 안정적 ID로 저장된 원본성과 등록 상태가 유지된다.
