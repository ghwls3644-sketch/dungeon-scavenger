# 아이템 규칙

## 목적

아이템 분류가 데이터, 저장, 거래, UI에서 어떻게 작동하는지 관리한다.

## 포함 범위

- 아이템 분류와 내부 식별자 원칙
- 감정 전후 상태와 판매 가능 여부
- 고유 유물·기록물의 획득 및 등록 플래그
- 반복 스폰, 저장 데이터, UI 구분, 판매 차단

## 제외 범위

- 아이템의 세계관상 의미와 반복 등장 개연성
- 사용자 표시 명칭의 정의
- 가격, 감정 비용, 수익 계산
