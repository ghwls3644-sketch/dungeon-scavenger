# 내러티브 전달 규칙

## 목적

세계관 정보와 발견물이 게임 안에서 노출·등록·재열람되는 시스템 규칙을 관리한다.

## 포함 범위

- 발견물 획득과 최초 발견 흐름
- 연구자 등록, 도감 해금, 텍스트 다시 보기
- NPC 반응 조건과 튜토리얼 노출
- 필수 정보와 선택 정보의 전달 방식

## 제외 범위

- 세계관 사실과 NPC의 지식 내용
- 화자별 어휘와 문체
- 아이템의 판매·저장·스폰 데이터 규칙
