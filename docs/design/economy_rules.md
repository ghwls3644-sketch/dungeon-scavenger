# 경제 규칙

## 목적

반복 조정 가능한 가격, 비용, 수익, 손실 완화 규칙을 관리한다.

## 포함 범위

- 기준 가격과 무게 대비 가치
- 감정 비용, 회수세, 수리비
- 거래처 및 난이도별 보정
- 탐험 순이익과 손실 완화 정책

## 제외 범위

- 비용과 시장이 존재하는 사회적 이유
- 아이템 분류와 저장 상태
- 구체적인 수치의 조기 확정
- NPC와 조직의 성격·지식·대사
- 판매·폐기 가능 여부와 원본 보호 플래그

## 책임 경계

| 책임 | 기준 문서 |
|---|---|
| 수색꾼 사회와 위험 외주화, 회수품 수요의 세계관상 이유 | [`../story/03_player_and_society.md`](../story/03_player_and_society.md) |
| 감정사·상인·길드 관리자의 역할과 태도 | [`../story/04_characters_and_factions.md`](../story/04_characters_and_factions.md) |
| 기준가, 거래처 보정, 비용, 정산, 난이도 보정과 재기 안전망 | 이 문서 |
| 아이템의 판매 보호, 감정 상태와 등록 처리 | [`item_rules.md`](item_rules.md) |

## 경제 설계 원칙

- 경제는 반복 탐험의 생계 압박과 더 들어갈지 귀환할지의 판단을 만든다.
- 정산에서는 총 판매액보다 실제로 남는 순이익을 우선해 보여준다.
- 한 번의 실패가 장기 진행을 막거나 재출정을 불가능하게 만들지 않는다.
- 난이도는 적 체력만 올리기보다 수리비, 보상 여유와 경제 부담을 조정한다.
- 고유 유물과 핵심 기록물은 판매액이 아니라 등록·정보·보상으로 처리한다.
- 가격·수수료·수리비와 안전망은 `EconomyRule` 데이터로 관리하고 코드에 직접 고정하지 않는다.
- 암시장은 MVP와 첫 출시 범위에서 제외한다.

## 경제 흐름

```text
출정 비용·소모품·장비 마모
→ 폐던전 탐험
→ 회수품 판매·감정·등록
→ 회수세·감정료·수리비 차감
→ 순이익
→ 하네스·장비·거점 서비스 개선
→ 더 깊고 위험한 수색
```

| 단계 | 경제 처리 |
|---|---|
| 출정 준비 | 출정 비용, 구매한 소모품과 선택한 서비스 비용을 기록함 |
| 탐험 | 회수품과 임시 획득을 모으고 장비 마모를 누적함 |
| 안전 귀환 | 들고 나온 물품, 장비 손상, 의뢰와 새 발견을 정산 대상으로 확정함 |
| 판매·감정·등록 | 판매 수익과 화폐가 아닌 등록·정보 보상을 분리함 |
| 비용 차감 | 회수세, 감정료, 수리비와 이번 출정에 귀속되는 비용을 표시함 |
| 순이익 확정 | 화폐 수입에서 비용을 차감하고 다음 출정에 쓸 수 있는 결과를 저장함 |

부분 성공도 회수품과 정보가 있으면 정상 정산한다. 안전 귀환하지 못한 현재 탐험의 미확보 회수품은 수익으로 잡지 않는다.

## 기준가와 거래처

- 길드가 품목별 기본 기준가와 [`회수세`](../reference/glossary.md#회수세)를 주도한다.
- 폐품은 대략적인 기준가를 감정 없이 확인할 수 있다.
- 미확인 물품은 감정 전 가치와 실제 분류를 숨기며, 허용할 경우에도 추정 범위와 실제 판매액을 구분한다.
- 상인과 공방은 자신들이 선호하는 특정 폐품·부품을 우대할 수 있다.
- 잔재는 감정 후 판매하거나 연구·수집에 사용할 수 있다.
- 고유 유물·핵심 기록물은 금전 기준가 대신 등록·정보 보상을 표시한다.

| 거래처 | 현재 가격·처리 역할 |
|---|---|
| 길드 | 공식 기준가와 회수세의 기준, 감정·등록 자격 제공 |
| 상인 | 특정 폐품이나 재료에 우대 가격 적용 가능 |
| 공방·장인 | 수리용 부품과 장치 재료에 우대 가격 적용 가능 |
| 연구자 | 잔재·기록물·특이 표본을 연구·등록 처리하며 일반 판매와 구분 |
| 암시장 | MVP와 첫 출시 범위에서 제외 |

원본은 길드가 감정 등급과 위험 수당도 정할 수 있다고 제안하지만 현재 GDD는 구체적인 계산 항목으로 확정하지 않았다. 거래처 우대를 가산, 배율 또는 별도 의뢰 보상 중 어떤 방식으로 적용할지도 아직 정하지 않는다.

## 정산과 순이익

정산 계산은 다음 관계를 유지한다.

```text
총 화폐 수입 = 회수품 판매액 + 화폐로 지급되는 의뢰·기타 보상
총 비용 = 출정 비용 + 소모품 비용 + 회수세 + 감정료 + 수리비
순이익 = 총 화폐 수입 - 총 비용
```

- 각 물품의 실제 판매액은 기준가에서 시작해 감정 상태와 거래처 우대 규칙을 적용한 결과다.
- 등록·정보 해금과 연구 진행은 화폐 수입에 합치지 않고 별도 보상으로 표시한다.
- 정산 화면은 총액, 비용 항목과 순이익의 관계를 플레이어가 이해할 수 있게 한다.
- 총 판매액보다 순이익을 더 크게 표시한다.
- 무게 대비 가치는 `예상 또는 확정 가치 ÷ 무게`의 비교 정보이며, 그 자체가 판매가를 바꾸지는 않는다.

0무게 물품, 대형 견인품과 화폐 가치가 없는 등록품의 무게 대비 가치 표시 방식은 아직 확정하지 않는다.

## 비용 항목

| 비용 | 발생 시점 | 조정 책임 |
|---|---|---|
| 출정 비용 | 출정 준비 | 기본 출정에 필요한 비용 범위와 면제·안전망 |
| 소모품 비용 | 구매 또는 사용 확정 | 구매가와 사용량 |
| 감정료 | 거점 또는 휴대용 감정 비용 확정 | 방식별 비용과 일괄 처리 보정 |
| 회수세 | 판매·정산 | 과세 대상과 세율 |
| 수리비 | 장비 손상 정산 | 손상도, 장비 유형과 정비 성장에 따른 비용 |

감정료를 물품별, 일괄, 등급별로 부과할지와 휴대용 감정 도구의 비용 구조는 아직 정하지 않는다. 회수세의 과세 기준, 수리비 공식과 출정 비용의 정확한 구성도 후속 밸런스 작업에서 결정한다.

## 난이도별 경제 보정

원본 `TBL-008`의 난이도 방향은 다음과 같다.

| 난이도 방향 | 수수료/세금 처리 |
|---|---|
| 쉬운 방향 | 감정 수수료 낮음, 회수세 약함, 손실 부담 적음 |
| 기본 방향 | 감정과 판매 과정에서 일정 비용 발생 |
| 어려운 방향 | 감정 전 판매 리스크, 높은 수리비, 높은 회수세로 생계 압박 강화 |

현재 GDD는 난이도에 따라 수리비와 보상 여유를 조정하되 기본 난이도에서도 실패 후 즉시 재기할 수 있어야 한다고 정한다.

- 쉬운 방향은 감정료·회수세·수리비와 실패 후 부담을 낮춘다.
- 기본 방향은 수입과 비용의 관계를 학습할 수 있는 기준값을 사용한다.
- 어려운 방향은 수리비·회수세를 높이거나 보상 여유를 좁힐 수 있지만 재출정 안전망은 제거하지 않는다.
- 감정 전 판매 리스크의 구체적인 판매 허용 여부와 가격 불이익은 아직 확정하지 않는다.
- 난이도 보정은 각 항목의 데이터 값으로 적용하고 별도 아이템 분류나 표시 명칭을 만들지 않는다.

## 실패 손실과 재기 안전망

| 항목 | 실패 시 처리 |
|---|---|
| 현재 탐험의 미확보 회수품 | 잃고 수익·정산 대상에서 제외 |
| 기본 하네스·영구 장비 | 잃지 않지만 내구 손상과 수리비 발생 |
| 기존 돈 | 유지 |
| 거점·연구 진행 | 유지 |
| 안전 귀환 전 고유 유물·기록물 | 영구 획득하지 않고 다음 탐험 후보에 남김 |

- 기본 장비와 최소 회복 수단을 보장해 파산으로 재출정이 막히지 않게 한다.
- 수리비는 실패의 비용을 만들지만 장착한 영구 장비를 통째로 잃는 방식으로 대체하지 않는다.
- 실패 직후 필요한 최소 출정 준비를 할 수 있어야 한다.
- 안전망은 장기 진행을 보존하지만 현재 탐험의 회수품 손실까지 되돌리지는 않는다.

보장할 기본 장비의 구성, 최소 회복 수단의 종류·수량과 수리비 감면 폭은 아직 정하지 않는다.

## 데이터와 표시

`EconomyRule`은 최소한 기준가, 수수료, 수리비와 재기 안전망 값을 관리한다. 계산에 쓰는 밸런스 수치와 콘텐츠 값은 코드에 직접 고정하지 않는다.

정산 화면은 다음을 구분해 표시한다.

- 물품별 판매액과 총 화폐 수입
- 회수세, 감정료, 수리비와 그 밖의 이번 출정 비용
- 최종 순이익
- 등록·연구·정보 해금처럼 화폐가 아닌 보상

UI는 계산 결과를 표시할 뿐 가격·수수료·안전망 규칙을 직접 소유하지 않는다. 내부 필드명, 통화 단위, 반올림 순서, 음수 순이익 표시 방식과 정산 화면 배치는 아직 정하지 않는다.

## 검증 기준

- 귀환 정산에서 총 화폐 수입, 비용과 순이익의 관계를 이해할 수 있다.
- 거래처 우대를 적용해도 같은 입력으로 같은 판매액을 계산한다.
- 감정료·회수세·수리비를 중복 차감하지 않는다.
- 고유 유물·핵심 기록물의 등록 보상을 판매액으로 잘못 합산하지 않는다.
- 기본 난이도에서 실패 직후 다시 출정할 수 있다.
- 어려운 방향에서도 한 번의 실패가 장기 진행을 막지 않는다.
- 난이도 보정 전후의 판매·수수료·순이익 계산을 독립적으로 테스트할 수 있다.
