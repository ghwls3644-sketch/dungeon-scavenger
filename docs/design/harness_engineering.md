# 하네스 엔지니어링

## 목적

수색꾼이 정면 전투 대신 도구로 위험에 대응하도록 하는 하네스의 시스템 규칙을 관리한다.

## 포함 범위

- 하네스의 핵심 동작과 모듈 경계
- 자원 소모와 회복 규칙
- 위험 대응 도구와 성장 축
- 하네스가 전투 장비로 변질되지 않도록 하는 금지선

## 제외 범위

- 던전과 잔존 에너지의 세계관상 원리
- 실제 코드 구조와 엔진 구현 세부
- 모듈별 최종 수치와 콘텐츠 목록
