# GDD 분할 운영 인덱스

이 디렉터리는 `GDD (통합본).md`를 운영 단위로 분할해 관리하기 위한 인덱스다.

## 문서 구성
- `01-overview-loop-world.md`: 게임 개요, 코어 루프, 세계관 요약
- `02-systems-catalog.md`: 4-1 ~ 4-37 시스템 카탈로그와 구현 우선순위
- `03-production-stack-roadmap.md`: 기술 스택, 로드맵, MVP 구현 전환 규칙

## 운영 규칙
- 신규 기획 반영 시 먼저 분할 문서를 업데이트하고, 이후 통합본에 병합한다.
- 통합본은 릴리즈/공유용 단일 문서로 유지한다.
- 충돌 발생 시 `기획 하네스 프롬프트.md`와 본 인덱스의 규칙을 우선한다.
