# 문서 이관 중 변경 대기열

문서 분할이 끝날 때까지 새 설정, 용어 변경, 긴급 정정은 이 문서에 먼저 기록한다. 원본과 아카이브는 직접 수정하지 않는다.

## 처리 규칙

- 일반 설정·용어 변경은 ID를 발급하고 대기시킨다.
- 긴급 오류 수정은 영향받는 원본 절과 이관 대상 문서를 함께 적는다.
- 문장 다듬기는 정합성 검토 단계까지 보류한다.
- 코드 ID, 저장 키, 번역 키는 구현 단계 전에는 확정하지 않는다.
- ID 형식은 `MIG-CHG-001`부터 순차적으로 사용하고 재사용하지 않는다.

## 대기 중 변경

현재 등록된 변경 없음.

## 반영된 변경

### MIG-CHG-001: 정합성 검사 시점 표시

- 요청일: 2026-07-27
- 요청 내용: 여러 날짜와 장소에서 작업을 이어갈 때 진행 방향이 달라지는 일을 막도록, 작업을 잠깐 멈추고 기준과 결과를 확인할 시점을 쉬운 문구로 미리 표시한다.
- 변경 이유: 대화에서만 안내하면 다른 환경에 인계되지 않으므로 저장소의 작업 안내와 이관 현황, 에이전트 규칙에 같은 검사 시점과 검사 목적을 남겨야 한다.
- 영향받는 원본 절: 없음. 게임 설정이 아닌 문서 작업 운영 규칙이다.
- 반영 대상: `docs/README.md`, `docs/project/migration_manifest.md`, `AGENTS.md`
- 긴급도: 일반
- 상태: `applied`
- 관련 결정·질문: 없음

### MIG-CHG-002: M4·M5 단계와 Git 인계 안내 정정

- 요청일: 2026-07-27
- 요청 내용: `DOC-0505` 시작 전 정합성 검사에서 확인한 M4·M5 단계 표기와 G-M4 통과 기록 누락을 바로잡고, 다른 환경용 Git 안내를 현재의 티켓별 커밋·작업 묶음별 push 규칙과 일치시킨다.
- 변경 이유: 기존 작업 결과와 다음 티켓은 계획에 맞지만 단계 경계와 Git 인계 문구가 서로 달라, 다른 날짜나 장소에서 G-M4를 건너뛰거나 티켓마다 바로 push하는 것으로 오해할 수 있다.
- 영향받는 원본 절: 없음. 게임 설정이 아닌 문서 단계·작업 인계 상태 정정이다.
- 반영 대상: `docs/README.md`, `docs/project/migration_manifest.md`
- 긴급도: 일반
- 상태: `applied`
- 관련 결정·질문: 없음

### MIG-CHG-003: Timeline 선후 관계와 범람 기준 정정

- 요청일: 2026-07-27
- 요청 내용: `DOC-0505`에서 발견한 마왕 봉인과 던전 증가의 선후 모순을 Timeline에서 제거하고, 폐던전 범람 위험의 현재 해석을 기존 결정과 일치시키며 Entity의 Story 역링크를 보완한다.
- 변경 이유: 원본은 마왕 봉인과 최초 던전 발생·모험가 시대의 선후를 확정하지 않지만 Timeline은 봉인이 먼저라고 기록했다. GDD 3-4의 `사라지거나 극히 낮다`는 표현도 GDD 3-3·18-1과 `DEC-004`의 `사라진다` 기준과 다르다.
- 영향받는 원본 절: `STY-0011`~`STY-0013`, `STY-0021`, `STY-0032`, `STY-0076`; GDD 3-3, 3-4, 18-1
- 반영 대상: `docs/reference/timeline.md`, `docs/reference/entity_index.md`, 관련 Story 역링크, `docs/project/m5_core_entity_timeline_review.md`
- 긴급도: 일반
- 상태: `applied`
- 관련 결정·질문: `DEC-001`, `DEC-004`; 새 열린 질문 없음
