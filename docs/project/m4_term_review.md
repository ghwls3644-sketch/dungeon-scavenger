# 공식 용어 검수 보고서

## 목적

`DOC-0501`에서 공식 용어의 독립 항목 누락, ID·표기 중복, Reference 책임 혼합 후보를 찾고 후속 정합성 티켓의 입력으로 남긴다.

`DOC-0501` 검수 범위에서는 문제 탐지와 분류만 수행했으며, 새 공식 표기, 용어 ID, 상태, 별칭, 폐기 명칭을 확정하거나 [`../reference/glossary.md`](../reference/glossary.md)를 직접 보완하지 않았다.

아래 누락·후보 표는 `DOC-0501` 검수 시점의 기록이다. 실제 기준 전환 결과는 `DOC-0503 처리 결과`에서 이어서 추적한다.

## 검토 기준

- 검토일: 2026-07-25
- 검토 티켓: `DOC-0501`
- 원본 기준: `스토리 정리 v1.5` 13-1~13-3
- 제품 기준: [`GDD`](../GDD.md) 부록 A
- 운영 기준: 최신 분할 제안서 11-3의 핵심 검수 용어 15개와 부록 D의 파일럿 시드 23개
- 활성 기준: [`공식 용어집`](../reference/glossary.md)의 등록 항목 12개와 Story·Design·Reference 문서의 실제 표기

### 판정 규칙

- `독립 항목 누락`: 핵심 검수 목록 또는 GDD 핵심 용어 요약에 있지만 고유 용어 ID와 항목이 없다.
- `검토 후보`: 파일럿 시드에 있으나 사용자 노출 여부나 Reference 소유 필요성을 더 판단해야 한다.
- `다른 Reference 소유`: 조직 식별이나 화자 표현이 이미 Entity Index 또는 Speaker Lexicon 책임으로 추적된다.
- `중복·경계 후보`: 같은 개념의 표기 변형이 있거나 서로 다른 개념이 별칭처럼 한 항목에 섞여 있다.

## 집계

| 검토 집합 | 용어 수 | 독립 Glossary 항목 있음 | 독립 항목 없음 |
|---|---:|---:|---:|
| 원본 13-1 기본 용어 | 12 | 12 | 0 |
| 제안서 11-3 핵심 검수 용어 | 15 | 12 | 3 |
| GDD 부록 A 핵심 용어 | 14 | 12 | 2 |
| 제안서 부록 D 파일럿 시드 | 23 | 12 | 11 |

현재 Glossary의 용어 ID는 12개, 공식 표기는 12개이며 ID 중복과 공식 표기 중복은 각각 0건이다. 기존 12개 항목은 모두 `ID`, `상태`, `공식 표기`, `짧은 정의`, `혼동 주의`, `상세 설정` 필드를 가진다.

원본 13-1의 12개 기본 용어는 빠짐없이 등록되어 있고 GDD 부록 A와 공유하는 짧은 의미에도 충돌이 없다. 아래 누락은 원본 13-1 이후 GDD와 제안서의 검수 범위가 넓어지면서 드러난 항목이다.

## 중복과 의미 경계 후보

| 표기 | 확인 결과 | 위험 |
|---|---|---|
| Glossary ID와 공식 표기 | ID 중복 0건, 공식 표기 중복 0건 | 현재 항목 내부의 직접 중복 없음 |
| 모험가 / 수색꾼 / 정찰 파견 | 상위 직업 분류, 현장 직업명, 공식 임무명이 `수색꾼`의 허용 별칭 필드에 함께 들어 있음 | 서로 교체 가능한 동의어처럼 오해할 수 있음 |
| 잔류물 / 회수품 | GDD는 `잔류물`을 상위 공식 표현으로 정의하고 여러 활성 문서는 `회수품`을 일반 총칭으로 사용함 | 포함 관계와 사용자 노출 우선순위가 불명확함 |
| 감정 수수료 / 감정료 | GDD와 Design에서 같은 비용 개념에 두 표기가 병존함 | UI·정산 문구가 흔들릴 수 있음 |
| 허가증 / 출입 허가 | 물리적 자격 증표와 행정 절차 표현으로 사용됨 | 아이템명과 서비스·권한명이 섞일 수 있음 |
| 감정 | 물품 판별 과정과 정서 의미에 같은 단어를 사용함 | 검색과 짧은 안내 문구에서 의미를 혼동할 수 있음 |

`코어방`, `폐 던전`, `잔여구역`, `잔존에너지`, `수색 꾼`, `고유유물`, `핵심기록물`처럼 현재 공식 표기의 띄어쓰기를 벗어난 변형은 활성 문서에서 발견되지 않았다.

`도적`, `잔반 처리`, `정찰자`는 공식 별칭이 아니라 화자의 비하·오해 표현으로 [`speaker_lexicon.md`](../reference/speaker_lexicon.md)에 분리되어 있다. 이 세 표현은 신규 공식 용어 후보나 `deprecated` 공식 명칭으로 보지 않는다.

`수색꾼` 항목의 허용 별칭에서는 `모험가`와 `정찰 파견`을 제거하고 각각 상위 직업 분류와 임무명인 독립 항목으로 연결했다. `잔류물`은 회수 대상의 상위 공식 표현으로 등록하고 `회수품`은 일반 설명 또는 실제 회수 결과를 가리키는 표현으로 경계를 남겼다.

전환 뒤 Glossary는 19개 ID와 19개 공식 표기를 가지며 직접 중복은 없다. `DOC-0501`의 독립 항목 누락 5개는 모두 해소했고, 파일럿 후보 8개도 등록·다른 Reference 유지·용어 비등록·열린 질문으로 처리 위치를 확정했다.
