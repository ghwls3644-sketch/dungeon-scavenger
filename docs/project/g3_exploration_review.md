# G3 탐험 확장 통합 검토

## 현재 판단

**게임 구현·검증은 DEV-0317까지, 후속 생존 규칙의 문서 정리는 DEV-0318까지 완료했으며 G3 전체 완료 판정은 아직 아니다.** DEV-0316의 기본 데이터 통합 경로에 더해, 현재 출정의 골렘 접촉 경고·포착 실패·회피/방전과 실제 짐 버리기의 탈출 효과를 확인했다. 건강·부상 상태와 퇴로 상실·비상 탈출의 구현은 남아 있다. 자동 결과만으로 사람의 긴장감·귀환 안도감이나 최종 밸런스를 입증할 수 없다.

**DEV-0317 — 골렘 접촉 위험과 생존 피드백**은 `6a002a8`에 로컬 커밋했다. 실제 시야 추적·중심 거리 34 px 이내 연속 접촉·1초 사전 경고는 현재 시제품의 시험 조건이며 최종 피해·건강·부상 규칙을 확정하지 않는다. **DEV-0318 — 생존 규칙과 시제품 범위 정리**는 문서 작성·검증 완료했으며 검증 결과 검토 후 사용자가 로컬 커밋을 승인했다. 다음은 `DEV-0319 — 건강·부상 상태와 HUD`이며 아래 범위 대조와 개발 인계의 검증 계약을 따른다. G4 기능은 아직 시작하지 않는다.

**정합성 검사: 아직 아님** — 이번 검토는 G3 기능 연결과 남은 범위를 확인하는 작업이며 기록된 다음 정기 검사는 G5 완료 후다. G1 사람 평가와 `Q-004`·`Q-005`는 기존 후속 상태를 유지한다.

## 재현 방법

저장소 루트에서 기존 [Godot 실행 환경](project_context.md#godot-준비)을 사용한다.

```powershell
& $env:GODOT_BIN --headless --path . --fixed-fps 60 --quit-after 18000 res://tests/smoke/g3_exploration_flow_smoke.tscn
& ./tests/run_g2_checks.ps1 -GodotBin $env:GODOT_BIN -Repetitions 2 -TimeoutSeconds 60
```

통합 장면은 `g3_exploration_flow_passed`와 종료 코드 0을 함께 확인한다. 골렘을 멈추거나 이동·충전·도구·물품의 값을 검사 편의에 맞게 바꾸지 않는다. 현재 출정의 3칸 가방과 충전 3, 기존 시험 데이터로 실제 이동·E/Q/F/G/Tab/M 입력을 사용한다. `InventoryItem`을 직접 삽입하거나 플레이어를 순간 이동시키지 않는다.

첫 명령에서 `--headless`를 빼고 끝에 `-- --g3-render-directory=<새 임시 폴더> --g3-report-path=<새 임시 JSON 경로>`를 붙이면 실제 화면 4장과 두 경로의 결과를 저장한다. 프레임 수는 입력 자동화의 길이이며 사람의 런 시간이나 최종 난이도 근거가 아니다. 그래픽 대기 프레임 때문에 headless 결과와 소폭 다를 수 있다.

## 같은 출정 안에서 확인한 연결

다음 표는 **DEV-0316 당시 경로와 결과**다. 원본 JSON도 당시 기록을 유지한다. DEV-0317에서는 골렘 접촉 위험이 생겼으므로 아래쪽 물품의 접근·귀환을 서쪽 통로로 바꾸었다. 현재 재현 절차와 결과는 이 문서의 수동 확인 순서 및 DEV-0317 보완 결과를 따른다.

| 경로 | 수행한 행동 | 최종 결과 |
|---|---|---|
| 무료 우회 | 위쪽 폐품 2개 회수 → 열린 오른쪽 문으로 아래쪽 진입 → 정밀 부품 회수 → 가방에서 무거운 폐품 선택 → 이동하며 빠른 버리기 → 오른쪽 길을 돌아 원래 입구 귀환 | 2개 회수, 예상 가치 90~130, 충전 3·유인물 2 유지, 잔여 구역 미발견 |
| 제한 자원 사용 | 공략도 단서 조사 → 위쪽 폐품 회수 → Q로 잔여 구역 입구 개방 → 실제 진입 후 함정 경고 확인·Q 안정화와 통과 → 오른쪽 문 닫기·Q 고정 → F 유인물 투척 중 지도 열기 → 재개·문 고정 만료·무료 개방 → 같은 회수/버리기/귀환 | 2개 회수, 예상 가치 90~130, 충전 0·유인물 1, 잔여 구역 1개 발견 |

두 경로 모두 무게 5.5에서 2.0짜리 물품을 버려 3.5가 된다. 실제 이동 속도는 **132→192 px/s**, 이후 걸음의 소음 반경은 **260→180 px**로 바뀐다. 자동 표시된 선택이 아니라 가방에서 직접 선택한 개체를 버리며, 귀환 결과에 버린 물품이 포함되지 않는다. 이 수치는 기존 조정 가능한 시험 값이다.

입구 개방·함정 안정화·문 고정은 같은 충전 3을 각각 한 번 사용한다. 유인물은 별도 재고 1개만 소모한다. 문 고정과 유인물 비행이 함께 진행 중일 때 지도를 열면 두 동작의 시간·플레이어·골렘 이동이 멈추고, Q/F 입력도 자원을 추가로 쓰지 않는다. 지도에는 실제 관찰한 닫힌 문이 막힘으로 표시된다. 지도 종료 뒤 시간이 다시 흐르고, 충전이 없어도 고정 만료 후 E로 문을 열어 귀환할 수 있다. 다음 출정은 새 물품·충전·도구·발견 상태로 시작한다.

## 수동 확인 순서

1. 타이틀의 새 게임에서 3칸 가방으로 출정한다. 위쪽 가벼운 폐품과 무거운 폐품을 E로 회수한다.
2. 북쪽에서 왼쪽으로 돌아 아래쪽 서쪽 통로로 진입한다. 불안정한 잔해의 경고가 끝나기 전에 멈추지 않고 통과하고, 정밀 부품의 왼쪽에서 E로 회수한다. Tab에서 세 물품의 가치·무게·분류와 아이콘을 비교한다.
3. 무거운 폐품을 직접 선택하고 가방을 닫는다. 왼쪽으로 이동하며 G를 길게 눌러 버린 뒤 HUD의 무게·이동·소음 변화를 확인한다. 서쪽 통로를 돌아 처음 입구에서 E로 귀환한다.
4. 새 출정에서는 왼쪽 아래 공략도를 먼저 조사한다. 위쪽 입구를 Q로 열고 실제 잔여 구역에 진입한다. 함정 왼쪽에서 경고를 확인한 뒤 Q로 멈추고 통과하거나 무료 우회한다.
5. 오른쪽 문 북쪽에서 E로 닫고 남은 충전으로 Q 고정한다. 위쪽을 향해 F를 던진 직후 M을 열어 탐험 정지·관찰한 막힘을 확인한다. 지도를 닫고 고정이 풀리면 E로 연다. 북쪽을 통해 서쪽 통로로 돌아 2~3번의 회수·귀환을 진행한다.
6. 접촉 위험은 별도 출정에서 오른쪽 통로로 골렘에게 접근해 확인한다. 추적 중 접촉 경고가 뜨면 Q로 방전하거나 거리를 벌린다. 방전하지 않고 접촉을 유지하면 실패 결과에 포착 이유와 이번 회수품 손실이 표시된다. 가방·지도 중에는 경고 시간이 멈춘다.

두 경로는 자원 선택과 시스템 연결을 재현하는 절차이며, 골렘 접촉으로부터 안전하다는 공략이나 균형 잡힌 최종 루트를 뜻하지 않는다.

## DEV-0317 보완 결과

2026-09-24 현재 출정의 골렘 접촉 위험과 실패 피드백을 추가했다. 실제 가시 추적 중 연속 접촉에만 경고 시간이 쌓인다. 거리 이탈·벽/닫힌 문으로 시야 차단·Q 방전은 경고를 취소하고 다시 접촉하면 전체 시간을 제공한다. 가방·지도 정지, 충전 부족, 잘못된 시험 데이터, 적 제거·출정 전후와 중복 실패를 검사했다. 결과 화면의 포착 이유는 일시적인 결과 데이터이며 기존 저장 형식은 유지한다. 미확인·보호 물품도 이번 손실에 포함되고 기존 거점의 돈·보관품은 저장·복원 뒤에도 유지된다.

북쪽의 같은 시작 배치에서 실제 회수품 3.0을 유지한 채 이동하면 192 px/s로 도망가다 포착된다. 가방에서 직접 선택한 2.0짜리 물품을 이동 중 G로 버리면 무게 1.0·240 px/s가 되어 기본 210 px/s 골렘과 거리를 벌리고 접촉 경고가 취소된다. 이는 배치를 통제한 기술 비교이며 기본 통합 경로 두 개와 별도다.

통합 경로에서는 골렘과 겹치던 오른쪽 접근을 피하고 서쪽에서 붕괴 경고 시간 내 통과·회수·서쪽 귀환을 실제 입력으로 진행했다. 적·물품·이동·충전·도구 기본 데이터는 바꾸지 않았다. `free_lower_passage`와 `limited_tools` 모두 회수품 2개·예상 가치 90~130, 버리기 전후 속도 132→192 px/s·소음 260→180 px이며 자원 결과는 이전과 같다. 이 경로는 골렘과의 직접 추적 비교를 대신하지 않는다. 기존 제품 순환 검사는 접촉 때 Q 방전 1과 이후 붕괴 안정화 1의 실제 비용을 검사하도록 보완했다.

최종 전체 **57/57 실행**(스모크 장면 34개 포함), 그래픽 검사 두 장면과 실제 화면 8장, 활성 문서 링크·원본 해시·공백 검사가 통과했다. 경고 UI를 기존 안내 영역으로 옮겨 북쪽 캐릭터와 적재 HUD를 가리지 않게 했다. 이번 [전체 실행 원본](dev0317_automated_results.json)과 [경로 측정 원본](dev0317_route_results.json)을 기존 DEV-0316 JSON과 따로 보존한다. [실행 명령·화면 경로·소스 해시](project_context.md#dev-0317-골렘-접촉-위험과-생존-피드백-검사)를 함께 확인한다. 검증 결과 검토 후 사용자가 로컬 커밋을 승인했으며 G3 전체 완료·사람 평가 통과는 선언하지 않는다. **정합성 검사: 아직 아님** — 다음 정기 검사는 G5 완료 후다.
