# G3 탐험 확장 통합 검토

## 현재 판단

**DEV-0316은 구현된 탐험 기능의 통합 검증 작업이며, G3 전체 완료 판정이 아니다.** 기본 데이터를 사용한 두 경로에서 회수·적재 비교·빠른 버리기·입구 귀환과 제한 자원·메뉴 정지를 확인했다. 그러나 골렘은 아직 접촉 손실·실패를 일으키지 않고 건강·부상 상태도 구현되지 않았다. 이동·소음 개선 수치만으로 실제 포착 회피나 사람의 긴장감·귀환 안도감을 입증할 수 없다.

다음 보완 후보는 **DEV-0317 — 골렘 접촉 위험과 생존 피드백**이다. 다음 착수 때 현재 출정의 포착 조건·사전 경고·방전/회피·실패 연결을 작은 범위로 정하고, 기존 G1 비교 장면과 최종 건강·부상 수치는 구분한다. 이 문서는 새 피해 규칙이나 즉사 조건을 확정하지 않는다. G4 기능은 아직 시작하지 않는다.

**정합성 검사: 아직 아님** — 이번 검토는 G3 기능 연결과 남은 범위를 확인하는 작업이며 기록된 다음 정기 검사는 G5 완료 후다. G1 사람 평가와 `Q-004`·`Q-005`는 기존 후속 상태를 유지한다.

## 재현 방법

저장소 루트에서 기존 [Godot 실행 환경](project_context.md#godot-준비)을 사용한다.

```powershell
& $env:GODOT_BIN --headless --path . --fixed-fps 60 --quit-after 18000 res://tests/smoke/g3_exploration_flow_smoke.tscn
& ./tests/run_g2_checks.ps1 -GodotBin $env:GODOT_BIN -Repetitions 2 -TimeoutSeconds 60
```

통합 장면은 `g3_exploration_flow_passed`와 종료 코드 0을 함께 확인한다. 골렘을 멈추거나 이동·충전·도구·물품의 값을 검사 편의에 맞게 바꾸지 않는다. 현재 출정의 3칸 가방과 충전 3, 기존 시험 데이터로 실제 이동·E/Q/F/G/Tab/M 입력을 사용한다. `InventoryItem`을 직접 삽입하거나 플레이어를 순간 이동시키지 않는다.

첫 명령에서 `--headless`를 빼고 끝에 `-- --g3-render-directory=<새 임시 폴더> --g3-report-path=<새 임시 JSON 경로>`를 붙이면 실제 화면 4장과 두 경로의 결과를 저장한다. 프레임 수는 입력 자동화의 길이이며 사람의 런 시간이나 최종 난이도 근거가 아니다. 그래픽 대기 프레임 때문에 headless 결과와 소폭 다를 수 있다.

## 같은 출정 안에서 확인한 연결

| 경로 | 수행한 행동 | 최종 결과 |
|---|---|---|
| 무료 우회 | 위쪽 폐품 2개 회수 → 열린 오른쪽 문으로 아래쪽 진입 → 정밀 부품 회수 → 가방에서 무거운 폐품 선택 → 이동하며 빠른 버리기 → 오른쪽 길을 돌아 원래 입구 귀환 | 2개 회수, 예상 가치 90~130, 충전 3·유인물 2 유지, 잔여 구역 미발견 |
| 제한 자원 사용 | 공략도 단서 조사 → 위쪽 폐품 회수 → Q로 잔여 구역 입구 개방 → 실제 진입 후 함정 경고 확인·Q 안정화와 통과 → 오른쪽 문 닫기·Q 고정 → F 유인물 투척 중 지도 열기 → 재개·문 고정 만료·무료 개방 → 같은 회수/버리기/귀환 | 2개 회수, 예상 가치 90~130, 충전 0·유인물 1, 잔여 구역 1개 발견 |

두 경로 모두 무게 5.5에서 2.0짜리 물품을 버려 3.5가 된다. 실제 이동 속도는 **132→192 px/s**, 이후 걸음의 소음 반경은 **260→180 px**로 바뀐다. 자동 표시된 선택이 아니라 가방에서 직접 선택한 개체를 버리며, 귀환 결과에 버린 물품이 포함되지 않는다. 이 수치는 기존 조정 가능한 시험 값이다.

입구 개방·함정 안정화·문 고정은 같은 충전 3을 각각 한 번 사용한다. 유인물은 별도 재고 1개만 소모한다. 문 고정과 유인물 비행이 함께 진행 중일 때 지도를 열면 두 동작의 시간·플레이어·골렘 이동이 멈추고, Q/F 입력도 자원을 추가로 쓰지 않는다. 지도에는 실제 관찰한 닫힌 문이 막힘으로 표시된다. 지도 종료 뒤 시간이 다시 흐르고, 충전이 없어도 고정 만료 후 E로 문을 열어 귀환할 수 있다. 다음 출정은 새 물품·충전·도구·발견 상태로 시작한다.

| 가치·무게·분류 비교 | 두 줄 목록·상세·아이콘과 문자, 미확인 정보 경계·보호·선택 개체의 개별/통합 검사 | 현재 시제품 범위 통과 |

| 기본 루트 밖 잔여 구역이 선택 목표 | 단서만 읽으면 비공개 유지, 실제 진입 때 발견, 함정 대응과 같은 입구 귀환 | 현재 시험 공간에서 확인 |

## 수동 확인 순서

1. 타이틀의 새 게임에서 3칸 가방으로 출정한다. 위쪽 가벼운 폐품과 무거운 폐품을 E로 회수한다.
2. 오른쪽 열린 문을 지나 아래쪽 정밀 부품을 회수한다. Tab에서 세 물품의 가치·무게·분류와 아이콘을 비교한다.
3. 무거운 폐품을 직접 선택하고 가방을 닫는다. 오른쪽으로 이동하며 G를 길게 눌러 버린 뒤 HUD의 무게·이동·소음 변화를 확인한다. 오른쪽 통로와 위쪽 경로를 돌아 처음 입구에서 E로 귀환한다.
4. 새 출정에서는 왼쪽 아래 공략도를 먼저 조사한다. 위쪽 입구를 Q로 열고 실제 잔여 구역에 진입한다. 함정 왼쪽에서 경고를 확인한 뒤 Q로 멈추고 통과하거나 무료 우회한다.
5. 오른쪽 문 북쪽에서 E로 닫고 남은 충전으로 Q 고정한다. 위쪽을 향해 F를 던진 직후 M을 열어 탐험 정지·관찰한 막힘을 확인한다. 지도를 닫고 고정이 풀리면 E로 열어 기존 경로를 따라 귀환한다.

두 경로는 자원 선택과 시스템 연결을 재현하는 절차이며, 골렘 접촉으로부터 안전하다는 공략이나 균형 잡힌 최종 루트를 뜻하지 않는다.
