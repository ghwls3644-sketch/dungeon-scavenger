# 화자 표현과 NPC 지식 정합성 검토

## 목적

공식 용어, 화자별 선호·회피 표현과 NPC가 실제로 아는 내용이 서로의 책임을 침범하거나 모순되지 않는지 검토한다. 이 보고서는 충돌과 보완 후보를 기록하며 새 대사, 지식, 인물, 집단, 용어 또는 식별자를 만들지 않는다.

## 검토 기준

- 검토일: 2026-07-25
- 공식 표기와 짧은 정의: [`../reference/glossary.md`](../reference/glossary.md)
- 화자별 어휘와 대사 표면: [`../reference/speaker_lexicon.md`](../reference/speaker_lexicon.md)
- 객관적 역사: [`../story/01_world_history.md`](../story/01_world_history.md)
- 수색꾼의 사회적 위치: [`../story/03_player_and_society.md`](../story/03_player_and_society.md)
- NPC·세력의 지식과 태도: [`../story/04_characters_and_factions.md`](../story/04_characters_and_factions.md)
- 연구자 지식의 진행 순서: [`../story/06_narrative_progression.md`](../story/06_narrative_progression.md)
- 상위 제품 기준: [`../GDD.md`](../GDD.md) 3장, 10장, 11장과 부록 B

검토 대상은 Speaker Lexicon의 화자·집단 8개, Glossary의 공식 용어 19개와 연결된 Story의 NPC·세력 지식 범위다. Speaker Lexicon의 `TBL-010`, `TBL-026` 연구자 단계별 표현도 같은 진행 단계에서 서로 다른 지식을 주장하는지 대조했다.

## 화자별 대조

| 화자 또는 집단 | 표현 기준 | 지식·태도 기준 | 판정 |
|---|---|---|---|
| 길드 / 행정 | `잔류물`, `회수세`, `모험가`, `정찰 파견`을 행정 범위에 맞게 구분 | 길드 관리자는 허가·의뢰·등록, 행정관은 회수세·출입·사고 처리를 담당 | 일치 |
| 상인 | 폐품·무게값·감정서를 실리적으로 사용하고 저주 소문을 꺼림 | 저주 소문이 붙은 물건은 거절할 수 있지만 감정된 잔재는 거래 가능 | 일치 |
| 수색꾼 | 현장 명칭 `수색꾼`과 폐품·잔재·잔여 구역을 사용 | 생존·회수 판단을 우선하며 튜토리얼 수색꾼은 기본 생존 정보를 전달 | 일치 |
| 감정사 / 연구자 | 분석적 표현과 연구자의 단계별 예시를 한 항목에 보관 | 감정사는 물품 판별, 연구자는 기록 해석과 지식 변화 담당 | 직접 내용은 일치하나 역할 경계 보완 후보 |
| 일반인 | 폐던전 물건을 저주·불길함으로 뭉뚱그리는 표현 | 객관적 원리보다 사회적 불안과 편견을 보여줌 | 일치 |
| 전직 모험가 | 지나친 방·건드리지 않은 물건·싼 목숨으로 과거 경험을 표현 | 유명 던전 경험과 위험 경고를 전달하는 선택 역할 | 일치 |
| 성직자 | 봉인·오염·금기·옛 악의 그림자를 가능성과 징조로 표현 | 마왕과 던전을 연결해 오해할 수 있으나 객관적 사실을 반드시 알지 않음 | 일치 |
| 수색꾼을 낮춰 보거나 오해하는 일부 모험가 | `도적`, `잔반 처리`, `정찰자`를 비하·오해 장면에서만 사용 | 수색꾼의 낮은 사회적 위치와 스카우트 가능성이 오해의 배경 | 직접 내용은 일치하나 근거 링크 보완 후보 |

## 공식 용어와 화자 표현 경계

| 표현 집합 | 기준 | 검토 결과 |
|---|---|---|
| `수색꾼` / `모험가` / `정찰 파견` | 현장 직업명 / 제도상 상위 분류 / 임무명 | 길드·행정과 수색꾼 항목이 세 범위를 섞지 않는다. |
| `도적` / `잔반 처리` / `정찰자` | 비하 또는 오해 표현 | Glossary의 공식 별칭으로 사용되지 않고 일부 모험가 항목에만 남아 있다. |
| `잔류물` / `폐품` / `잔재` | 행정 상위 표현 / 물리적 회수품 / 마력·기억 흔적 | 길드·행정, 상인, 수색꾼이 각 화자 범위에 맞는 표현을 사용한다. |
| `감정` / `감정서` | 공식 행위·시스템 / 상인이 사용하는 화자 표현 | `감정서`는 공식 용어로 승격되지 않고 Speaker Lexicon 책임을 유지한다. |
| `마왕의 저주` / `봉인의 균열` / `옛 악의 그림자` | 사회적 믿음과 신앙적 해석 | 객관적 역사나 Glossary 정의로 사용되지 않는다. |
| `감정료` / `감정 수수료`, `허가증` / `출입 허가` | 공식 표기 미정 | 각각 [`Q-017`](open_questions.md), [`Q-018`](open_questions.md)로 분리되어 화자 표현 검토에서 새 표기를 확정하지 않았다. |

## 연구자 지식 단계 대조

| 단계 | Story의 지식 기준 | Speaker Lexicon의 두 예시 묶음 | 판정 |
|---|---|---|---|
| 초반 | 마왕 전승과 던전 기록의 관계를 판단 유보 | 같은 원인이라 보기 어렵거나 증거가 부족하다고 표현 | 일치 |
| 중반 | 봉인보다 지맥·마나 이상과 더 자주 겹친다는 정황 확인 | 플레이어가 가져온 기록을 근거로 같은 정황을 언급 | 일치 |
| 후반 | 사회적 오해와 객관적 현상을 분리하고 직접 인과 증거가 부족하다고 판단 | 마왕의 이름이 덧씌운 공포일 수 있으며 직접 원인을 단정하지 않음 | 일치 |

`TBL-010`과 `TBL-026`은 단계마다 서로 다른 결론을 요구하지 않는다. 여섯 문장은 같은 지식 단계를 표현하는 문장 변형이며, 정확한 전환 조건이나 원본에 없는 추가 지식을 만들지 않는다.

## 직접 충돌 목록

직접 충돌은 없다.

- 공식 용어가 은어나 비하 표현으로 대체된 항목: 0건
- 객관적 사실과 사회적 믿음이 같은 사실로 합쳐진 항목: 0건
- 연구자의 초·중·후반 지식 순서가 뒤바뀐 항목: 0건
- NPC 역할에 원본에 없는 확정 지식이 추가된 항목: 0건

## DOC-0601 처리 결과

- 감정사·연구자의 기존 공동 ID와 공통 분석 어휘는 유지하고, 단계별 지식 변화와 현재 대사 예시는 연구자 전용이라고 명시했다.
- 일부 모험가 항목의 지식 범위에 수색꾼의 사회적 위치를 설명하는 [`03_player_and_society.md`](../story/03_player_and_society.md)를 추가했다.
- 새 표현, 대사, 화자, ID, 결정 또는 열린 질문은 만들지 않았다.
- 사람 승인과 상태 승격 후보는 [`m6_human_review.md`](m6_human_review.md)에 기록했다.
