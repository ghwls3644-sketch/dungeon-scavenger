`Q-009`~`Q-011`은 GDD 19장에서 의도적으로 확정하지 않는 배경 여지로 분류한 항목이다. 현재 제품 구조를 막지 않으며 위 검토 조건이 생기기 전에는 결정을 요구하지 않는다.

`DEV-0107` 플레이테스트 장면은 적재 선택을 재현하기 위해 슬롯 2개, 부담 2.5, 과적 4.0과 짧은 시험 공간을 사용한다. `DEV-0108`의 조사·미확인 물품 공간도 상태 전달 검사용 임시 한도와 무게만 사용한다. 이 값들은 자동 검사 자료일 뿐 목표 런 시간이나 제품 슬롯·무게 단계·감속률의 근거로 확정하지 않는다. 2026-08-31 G1 정합성 검사에서도 사람 플레이테스트 자료가 없어 `Q-004`·`Q-005`를 결정하지 않았다.

`DEV-0111`은 같은 우회 경로에서 가방 2칸·3칸을 비교하고 탐험·가방 확인 시간과 적재 기록을 수집한다. [G1 검토 기록](g1_playtest_review.md)에 자동 자료와 사람 질문을 남겼다. 자동 입력의 짧은 시간으로 15~25분 가안의 정확한 목표를 선택할 수 없고, 당시에는 무게 감속도 구현하지 않아 최종 감속률을 판단할 근거가 없었다. 실제 사람 검토와 미확정 항목 처리에 관한 사용자 판단 전까지 `Q-004`·`Q-005`는 `provisional`로 유지하며 G1 통과를 선언하지 않는다.

2026-09-06 후속 보완에서는 통합 시험 장면의 경고 시간·추적 속도를 조정하고, 같은 경로에서 무료 통과와 충전 대응의 추적·경고 시간을 비교했다. 두 조건 모두 생환할 수 있으며 자동 기록은 대응에 따른 상태 유지 시간의 차이만 보여 준다. 사람의 긴장감·판단 부담이나 최종 런 시간·슬롯·무게·감속 수치를 결정한 근거로 사용하지 않는다.

2026-09-08 사용자의 작업 재개 지시에 따라 `DEV-0201`의 제품 시작 흐름을 진행한다. 위 사람 확인과 미정 수치는 별도 후속 항목으로 유지한다. 실제 플레이 의견 없이 G1 사람 평가를 통과 처리하지 않으며, 이미 완료한 기술 검사를 반복해 타이틀·거점 개발을 막지 않는다.

2026-09-19 `DEV-0307`에서 현재 출정 장면에 무게별 이동 감속을 연결했다. 정상 1배·부담 0.8배·과적 0.55배는 조정 가능한 시험 값이다. 자동 검사로 단계별 이동과 버리기 후 회복을 확인했으나 사람의 긴장감·귀환 판단·추적 난이도를 평가한 것은 아니다. G1 비교 장면과 과거 측정 조건은 유지하며, `Q-005`의 슬롯·무게 경계·최종 감속률과 사람 평가는 계속 `provisional`이다. 당시 후속으로 남긴 적재 소음 구현은 아래 DEV-0308에서 다룬다.

2026-09-19 `DEV-0308`에서 현재 출정 장면의 실제 이동 소음과 골렘 반응을 연결했다. 걸음 48 px·정상/부담/과적 반경 96/180/260 px·2초 안의 큰 소음 3회는 조정 가능한 시험 값이다. 직선 거리로 발생 순간 위치를 전달하며 벽 차음이나 새로운 길찾기는 구현하지 않았다. 반복 큰 소음은 기존 경고 뒤 추적으로 이어지고, 버리기로 단계가 낮아지면 이후 이동 소음 범위도 줄어든다. 자동 검사는 동작 경계만 검증하며 소음의 공정성·인지성·긴장감과 `Q-005`의 최종 밸런스는 사람 평가가 남아 있다.

## 생존 규칙 검토 경계

2026-09-24 `DEV-0318`에서 `Q-019`~`Q-021`을 추가했다. 새로운 세계관 질문을 만든 것이 아니라 GDD 4-3·6-2·9-1·12-3에 요구된 건강·부상·퇴로 상실의 상세 처리 공백을 추적한다. 기존 `Q-014`는 허가 약관과 사회적 사고 책임의 범위다. 이를 근거로 피해 수치·치료비·보험·구조자의 정체를 결정하지 않는다.

[생존 규칙 검토안](../design/survival_rules.md)은 건강 잔량과 일시적 부상을 분리한다. DEV-0318 문서 작업 자체는 기존 실행 규칙을 바꾸지 않았다. 2026-09-25 DEV-0319에서 GDD·confirmed Design과 대조하고 `MIG-CHG-028`에 먼저 기록한 뒤 건강 2·함정 피해 1·부상 6초·이동 0.9를 현재 출정에 시험 적용했다. 첫 함정 피해는 살아남고 다음 피해는 실패하며 골렘 포착·붕괴는 잔량과 무관한 행동 불능이다. 새 출정 초기화는 임시 실행 정책이고 건강/회복/비용의 최종 결정이 아니다. 질문·문서 등록이나 자동 검사 통과를 최종 규칙 승인으로 기록하지 않는다.

검토안의 비상 탈출 성공에 대한 회수품 처리는 미정이다. 현재 기준이 정한 것은 제한 시간 만료 또는 비상 탈출 실패의 손실이며, 성공을 무료 귀환이나 전량 손실로 임의 해석하지 않는다. 마지막으로 관찰한 막힌 길을 실제 퇴로 상실로 간주하지 않는다. 부상 시간·이동 계수의 시험 값은 위와 같고, 조사·회수의 시험 시간/효율은 DEV-0320의 `MIG-CHG-029`에 먼저 기록했다. 비상 탈출 시간/비용은 구현용 시험 값도 후속 착수에서 따로 기록한다.

G1 사람 평가·`Q-004`·`Q-005`와 기존 안전망 비용 미정 상태는 유지한다. 새로운 건강·부상·퇴로 시제품의 자동 검사를 통과하더라도 해당 사람 평가와 최종 밸런스가 해결된 것으로 처리하지 않는다.

2026-09-28 DEV-0323에서 기본 출정의 부상 회수·귀환과 별도 공간의 비상 탈출 성공/시간 초과를 실제 앱의 결과·정산·파일 저장·재출정·새 실행 이어하기까지 대조했다. 시제품 기술 범위의 G3는 완료하고 다음 DEV-0401부터 G4로 전환한다. 이 검토는 Q-019~Q-021의 최종 값·정식 지형 적용·사람 평가를 해결하거나 생존 규칙 검토안을 confirmed로 바꾸지 않는다. [완료 판정과 후속 경계](g3_exploration_review.md#dev-0323-g3-보완-통합-검토)를 따른다.

## 수리 규칙 검토 경계

2026-10-01 DEV-0405에서 GDD 4-4·7-4·10장과 confirmed Economy Rules의 수리비·재기 안전망에 남아 있는 구현 공백을 Q-022·Q-023으로 추적했다. 새 세계관 질문이나 Q-014의 사회적 사고 책임을 수리 정책으로 바꾼 것이 아니다. 건강/부상·회복은 Q-019·Q-020, 비상 탈출은 Q-021의 기존 책임을 유지한다.

사용자는 **거점에서 비용을 확인하고 선택 수리**를 답변했다. 거래 방식은 [DEC-111](decisions.md#dev-0405-수리-방식-선택)로 결정했지만 손상량·가격·부분 수리·무료 복구의 자격/양은 해결하지 않았다. [수리 검토안](../design/repair_rules.md)은 DEV-0406의 제한된 손상 시험 적용과 미적용 수리/안전망 제안을 구분한다. 손상 수치도 최종 밸런스의 확정은 아니다. 문서 커밋이나 기술 검사 통과를 수치·정책 전체 승인으로 해석하지 않는다.

DEV-0406에서 장비 손상 상태와 저장을 연결했다. 다음 DEV-0407은 거점 선택 수리와 최소 복구다. 이후 수리와 최소 복구를 함께 구현·검증한 뒤에만 손상에 따른 출정 제한을 연결한다. 돈 0·판매품 없음·내구 0에도 실제 다음 탐험으로 들어갈 수 있어야 하며, 무료 복구가 돈/판매품 지급이나 반복 보상으로 이어지면 안 된다. 그 구현 전까지 현재 무료 출정·새 출정 건강/충전의 시험 동작을 유지한다.

2026-10-01 DEV-0406의 시제품은 결과 저장 때 손상을 한 번 반영하고, 구형 1·2의 내구 3 보완·스키마 3 저장·새 실행의 내구 0 보존을 검사했다. 읽기·실패한 저장·중복 정산은 내구를 추가로 바꾸지 않는다. 내구 0·돈 0·판매품 없음의 실제 재출정은 유지한다. [시험 적용](../design/repair_rules.md#dev-0406-손상-상태-시험-적용)은 수리/안전망의 조건 확정이나 Q-022·Q-023 해결을 뜻하지 않는다.
