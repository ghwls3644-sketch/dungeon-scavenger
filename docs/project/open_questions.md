# 열린 질문

## 목적

미결정, 가안, 보류 항목을 기준 본문과 분리해 추적한다.

## 포함 범위

- 검토 중이거나 임시 원칙만 있는 질문
- 영향 문서와 다음 검토 조건
- 해결 후 연결할 결정 ID

## 제외 범위

- 이미 승인된 결정
- 원문에 없는 질문의 임의 생성
- 단순 문장 다듬기 요청

## 질문 목록

| ID | 질문 | 상태 | 영향 문서 | 임시 적용 원칙 | 다음 검토 조건 |
|---|---|---|---|---|---|

원본의 추가 검토 메모는 후속 Project 문서 정리 티켓에서 등록한다.
