# 하네스 실행 입력 템플릿

아래 3개 필수 입력을 채운 뒤 `기획 하네스 프롬프트.md`에 붙여서 실행한다.

```text
이번 요청 주제: [예: T-33 귀환 구간 동적 위험 증폭 규칙 설계]
대상 플레이어 경험 목표: [예: 귀환 직전 긴장감 피크를 높이고 생환 성취감 강화]
개발 우선순위: [예: 일정 단축 > 리스크 최소화 > 실험성]
```

선택 입력(필요 시):

```text
난이도 타깃: [예: 중간 난이도, 초회 생환률 40~55%]
세션 길이 목표: [예: 20~30분]
참고할 기존 시스템: [예: 4-1 소음/어그로, 4-7 중량 페널티, 4-21 실패/부분 회수]
```
